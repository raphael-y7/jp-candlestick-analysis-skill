## I — 方法自述

这张卡把一根孤立的 K 线读成一组**可登记的状态数据**，是后续一切形态判读的阈值口径与价位来源。

读法顺序：先拆实体、影线、颜色；再用阈值判"长实体"（实体 ≥ 前一天实体的 3 倍——作者自认主观标杆）；随后给颜色倾向与影线环境判读——长上影只有出现在高价区/阻力区/超买区才值得重视，长下影落在支撑区/超卖区说明空头失控，高浪线（长影线+小实体居中）=市场丧失方向感；然后做位置定性（低价区/高价区，客观标尺由差异指数卡供给），并把长实体的中点、底、顶登记为未来的支撑/阻力带。

两个进阶读法：**开盘先行**——次日开市价相对前实体中点的位置预示短期强弱（开在长白实体中点以下=空头态势警讯；开在前黑实体中点以上=积极信号），A股须过滤集合竞价噪声；**动量衰减**——长实体之后接小实体序列说明供需重新均衡（配合摆动指数超买预警顶部），横盘期黑实体又多又长说明空头占优，而"近期最长"的长黑是控制权易手的确认。

## A1 — 应用示例

c11 兼作单根判读素材——上书第九章图 9.1 练兵图判读第 1 条（reported_case）："一根长上影线的蜡烛线……表明多方有些犹豫，不过这条线索微不足道，因为一个时段的长上影线不足以改变市场方向的基调。"——示范孤立影线必须环境加持。

以下为**明确标注的合成演练**（V2 演练沿用，原书未为本单元设独立算例；规则取自原书）：

- **长实体判定**: 前日实体 2 元，今日实体 6.10 元 ≥ 3×2 → 判长白实体（阈值按 3 倍声明）。
- **开盘先行**: 长白实体区间 11.90-18.00，中点 14.95；次日开市 15.10 > 14.95 → 读"积极信号"。
- **捉腰带失效**: 某日开市即光脚阳线（开盘=最低价）构成看涨捉腰带，其后某日收市跌破该捉腰带线低点 → 信号失效。

## A2 — 触发场景 ★

### 用户会在什么情境下需要这张卡？

1. "今天这根大阳线/大阴线/长上影说明什么"——单根读数请求。
2. "昨天涨停今天低开，怎么看"——开盘先行法的典型问句。
3. "光脚阳线/光头阴线是什么信号"——捉腰带线家族。
4. 连续小实体群中出现一根显眼 K 线，问"这根有没有意义"。
5. 复盘时需要把单根 K 线的支撑/阻力带登记进价位表。

### 语言信号（中英双写）

- "大阳线 / 长阴线 / 长上影 / 长下影"（long white/black body, upper/lower shadow）
- "光脚 / 光头 / 捉腰带"（belt-hold line, marubozu-like open）
- "高开 / 低开"（gap open, opening price signal）
- "动量减弱 / 涨不动了 / 连续小实体"（momentum fading, small bodies, spinning top）

### 与相邻能力卡的区分

- 与 `doji-context` 的区别：十字线（开≈收）专由 C09 处理；本卡判"有实体的单根"。执行中若发现开≈收 → 转 C09。
- 与 `volume-confirmation` 的区别：本卡只读价格结构；成交量核对与积聚/派发由 C04 完成。
- 与 `data-quality-confirmation-gate` 的区别：读数前数据口径由 C02 把关；本卡不重复自查。
- 与 `divergence-index` 的区别："低价区/高价区"定性在本卡只做粗判，客观标尺（收盘价对均线的偏离）由 C18 计算。

## E — 执行步骤

**必需输入**: 单根或多根 OHLC（或可转述的开/收/高/低）。只有涨跌幅而无 OHLC 时，先索取或复算 OHLC，不得跳过。
**交付物与完成标准**: 单根信号清单（名称+多空倾向+强弱定性）+ 支撑/阻力登记表 + 次日开盘观察点。

1. **解析与长实体判定**
   - 拆实体/影线/颜色。长实体判据：实体 ≥ 前一天实体长度的 3 倍（L4140；下书术语表同口径）。作者明示主观标杆 → 本次分析声明所用倍数（默认 3；1.5-3 倍灰色地带标注"存疑"，按标的自测，G1）。
   - 完成标准：每根给出"长实体 / 普通 / 小实体"三档。

2. **颜色倾向与影线环境**
   - 长上影：仅在高价区/阻力区/超买区重视；长下影：支撑区/超卖区=空头失控（看涨线索）；高浪线=丧失方向感。
   - 横盘环境黑白统计：黑实体多且长=空头占优。
   - 完成标准：每根附环境条件；孤立影线明确标注"微不足道"（图 9.1 判读第 1 条）。

3. **位置定性与价位登记**
   - 位置定性（低价区/高价区）为粗判，精确标尺接 `divergence-index`。
   - 登记：长实体中点=支撑/阻力带；长实体底=支撑、顶=阻力。
   - 完成标准：登记表含具体价位与依据。

4. **开盘先行法（次日验证点）**
   - 次日开市价 vs 前实体中点：开在长白实体中点以下=空头态势警讯；开在前黑实体中点以上=积极信号。
   - A股适配（G2）：9:25 集合竞价产生的高开低开含噪声，观察点以 9:30 后实际成交口径复核（原书未讨论，属自定约定）。
   - 完成标准：给出具体观察价位（前实体中点数值）。

5. **动量衰减判读**
   - 长实体后接小实体序列=供需重新均衡（配合 RSI 超买预警顶部）；"近期最长"的长黑=空头接管确认。
   - **判停分支**：发现开≈收 → 转 `doji-context`；数据口径存疑 → 回 `data-quality-confirmation-gate`；两者处理完再回本卡剩余步骤。

## B — 边界 ★

### 不要在以下情况使用此卡
- 开≈收的十字线——那是 `doji-context` 的领地，硬按实体逻辑判读会丢掉"多空平衡"这个核心信息。
- 箱体中部的孤立长上影/长下影——图 9.1 明示单根影线"微不足道"，须环境加持。
- 未过数据门的数据——开盘价被前收盘冒充时，开盘先行法整体失效。

### 书中警告的失败模式
- x06（判据弹性双向失败）：图 4.7 的 2 月 22 日被作者亲自标注"不是锤子线"（下影线不足 2-3 倍）；但反过来，1.5 倍灰色地带被机械排除也是错——判据是弹性区间不是硬边界；且两书判据不一致（上书 2 倍 / 下书 3 倍）。
- x17（魔法数字须自测）：3 倍阈值、捉腰带位置条件均为经验标杆，跨标的搬用会信号饥饿或泛滥。

### 作者盲点（阶段 0 批判）
- 无统计回测（G3）；1990s 美国样本；3 倍阈值须按标的自测（G1——建议先统计目标个股近一年实体分布再声明阈值）。

### A股制度适配注意
- 集合竞价噪声（G2，注册表指定）：开盘先行法在 A股须以连续竞价后的价格复核。
- 涨跌停：A股涨停长实体（10%/20% 满幅）与美股量纲不可比——按标的自测阈值时必须包含涨跌停样本；一字板实体信息为零。
- T+1：开盘先行读出的"警讯/积极信号"最快次日才能执行，隔夜跳空风险须计入。
