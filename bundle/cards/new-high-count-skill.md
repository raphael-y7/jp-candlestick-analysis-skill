# 迭创新高（低）计数与超买超卖预警

## R — 原文依据

> "迭创新高（低）形态的构成中，新高蜡烛线或新低蜡烛线不必是连续（不间断）出现的，计点时要忽略其间出现的横向盘整的蜡烛线。但是，一般来说，在两个新高（低）蜡烛线之间的盘整蜡烛线不应该超过两或三根，也不应该出现强劲的反向蜡烛线。"
>
> — 下书《日本蜡烛图技术新解》上篇第 3 章"迭创新高（低）"节（图 3-76a/b；阈值口径同节："8~10根只是个参考标杆而已……有些市场则可能是6根或者12根"）

---

## I — 方法自述

这套方法给"涨多了/跌多了"一个可数的口径：不用任何指标参数，只数收盘价连续刷新极值的根数。

1. 先锁定上一轮行情的极点（最低点/最高点），从极点之后第一个创新高（低）的蜡烛线记 1，此后每刷新一次极值记一档。
2. 两档之间允许夹不超过两三根横盘蜡烛线（跳过不计数），但一旦出现强劲反向蜡烛线，计数就断了。
3. 累计到 8–10 档（参考标杆，各市场 6–12 不等）视为超买（超卖）警戒区：停止顺势加仓、准备变现——不是反向开仓。
4. 若行情用横盘或大幅修正把绷紧的弦放松了，形态不再存在，从新极点重新计数。

它回答的问题是"现在算不算极端"，不回答"何时反转"——反向动作仍须等本计数之后出现的蜡烛图信号。它也可以叠加在新价图（三线图/钥匙图）上，对连续同色线做同样的计数。

## A1 — 应用示例

### 示例 1: 日本技术分析师协会会员的"8 个新低 + 双高点阻力"判读
- **类型与来源**: reported_case，下书《日本蜡烛图技术新解》下篇第 6 章·图 6-14（作者与日本技术分析师协会会员的通信判读）
- **问题/输入**: 三线反向突破图上的下跌行情，反弹目标与超卖判断怎么定？
- **方法论的使用**: 该会员在三线图上叠加"迭创新低计数"——市场创下 8 个新低即达参考区间下沿，判断超卖、反弹可期；同时把 x、y 两阶段峰值（60 美元附近双高点）登记为未来阻力。
- **结论**: 8 个新低计数 + 60 美元双高点共同给出"反弹会受阻于 60 美元"的预警框架。
- **结果**: 1993 年下半年行情反弹果然受挫于 60 美元阻力区，转而下行至 45 美元附近（原书判读）。

### 示例 2: 合成演练（原书未提供可复算的完整计数案例，以下为明确标注的合成演练——注册表 V2 演练）
- **问题/输入**: 个股自 8.00 元低点起上行，其间夹两段各 ≤2–3 根的横盘小实体，随后收出 6% 单日大阴线。
- **方法论的使用**: 两段横盘无强劲反向蜡烛线 → 跳过不计数，累计计得 9 档新高 → 达阈值：停止顺势加仓、准备变现；随后 6% 大阴线属"大幅修正" → 超买化解、形态不再存在 → 从新极点重新计数。
- **结果**: 演算输出与规则预期一致（9 档预警 + 重置事件），可按 E 段步骤逐日复算。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 持仓涨幅已大，问"是不是涨太多了、该不该止盈/减仓"，手里没有量化口径。
2. 行情连续创新高/新低（A股连板股、沿五日线爬升的趋势股），想数"数到第几个了"。
3. 下跌途中问"跌这么多了是不是快见底"，需要一路不依赖摆动指数的独立计数读数。
4. 已有 RSI/KDJ 读数，想用另一路方法交叉核对"极端"判断是否成立。

### 语言信号 (用户的话里出现这些就应激活)

- "迭创新高 / 连续新高 / 连续新低"（a series of new highs / consecutive new highs / 8-10 new highs）
- "涨（跌）太多了 / 拉升太猛 / stretched too far, overextended"
- "酒田骨头 / 数新高 / 数新低"
- "该不该止盈了 / 是不是超买了 / oversold enough to buy?"

### 与相邻 skill 的区分

- 与 `divergence-index`（C18）的区别: 差异指数是"价格对均线的偏离百分比"标尺（软件叫乖离率），本卡是"极值计数"，两路独立读数可互证、互不替代。
- 与 `oscillator-confirmation`（C19）的区别: 摆动指数读数软件自带且只产出警告级结论（积雨云）；本卡不依赖任何指标参数，是原生的计数口径。
- 与 `three-line-break-chart` / `kagi-chart-skill`（C23/C25）的区别: 新价图上可对连续同色线做同样计数，但画图规则与转向线体系归那两张卡；本卡只讲计数规则本身。

## E — 执行步骤

**必需输入**: 收盘价序列（或新价图线序列）+ 计数方向（新高/新低）+ 阈值声明（默认 8–10，用户标的须自测，见 B）。若找不到明确的此前趋势极点（横盘箱体），先询问或判停——横盘中没有"极点之后"可数。
**交付物与完成标准**: 当前计数档位 + 预警状态（未达/已达阈值）+ 重置事件记录；每个判定给出对应日期与收盘价，保证逐日可复算。

1. **定极点**
   - 此前趋势的最低（高）点确定后，其后第一个创新高（低）的蜡烛线记 1。
   - 完成标准: 极点日期与"记 1"日期唯一确定。
   - 判停: 无明确此前趋势极点（横盘箱体）→ 输出"本形态不适用"并停止。

2. **逐档计数**
   - 执行口径（本卡约定，须先声明）: 收盘价创新高才记下一档。原书图 3-76a 图示口径为"交易时段（含上影线）创新高"，两版并列，取一版并全程一致。
   - 完成标准: 每档对应唯一日期与收盘价。

3. **中断核查**
   - 两个新高之间的蜡烛线: 盘整 ≤2–3 根 → 忽略继续数；出现强劲反向蜡烛线或盘整超过 2–3 根 → 计数中断，转第 5 步。
   - 完成标准: "继续/中断"判定有逐根依据。

4. **达阈值动作**
   - 计到 8–10 档（或自测阈值）→ 停止顺势加仓、准备变现（跌势对称: 停止卖出、准备承接）。
   - 判停: 此时不反向开仓——原书明示反向动作（卖空/买入待反弹）须等本形态之后出现蜡烛图信号。
   - 完成标准: 预警状态 + 对应动作档输出。

5. **重置分支**
   - 横向盘整或大幅修正任一出现 → 超买（超卖）已化解，形态不再存在 → 从新极点重新计数。
   - 完成标准: 重置事件含日期与新极点。

6. **输出登记表**: 日期 / 收盘价 / 档位 / 判定依据（新高·跳过·中断·重置）/ 预警状态。

## B — 边界

### 不要在以下情况使用此 skill

- 横盘箱体: 没有可数的"极点之后"趋势，计数无意义（与 C01/C02 的判停口径一致）。
- 把达阈值当反向开仓指令: 原书只说"停止买进（或变现）"，卖空要等形态后出现空头信号。
- 用单根长阳创新高就往计数里加戏: 本卡只数"创新高"这一事件，实体长短的读数归 C03。

### 作者在书中警告的失败模式

- 魔法数字（x17）: "对于新高（低）蜡烛线的数目不必过于拘泥，8~10根只是个参考标杆而已，每个市场都有自己的特点……有些市场则可能是6根或者12根"（下书第 3 章）——照搬 8–10 到自己的标的是参数搬运错误。
- 中断条件（≤2–3 根盘整、无强劲反向蜡烛线）同样是弹性判据，须事先声明自己的执行口径。

### 作者的盲点 / 时代局限

- 作者只给"不必拘泥"的告诫，没给测试方法论（样本、显著性、样本外验证）——阈值自测存在数据挖掘/过拟合风险（G1）；全书无统计回测，"超买易回调"是案例归纳。
- 样本为 1990 年代美国市场，牛市偏差可能抬高形态观感（阶段 0 批判）。

### A股制度适配（G2 缺口）

- 一字涨停/跌停与连板股的高低价被制度压平，连续新高可能在极短时间内凑满计数，波动结构与美股不同，阈值更须自测。
- 停牌复牌造成的跳空创新高算新一档还是中断，原书未讨论——须事先声明口径；涨跌停制度下"大幅修正"的幅度判定建议按标的自测。
