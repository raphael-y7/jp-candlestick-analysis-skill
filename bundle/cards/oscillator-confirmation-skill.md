# 摆动指数三要素与"积雨云 vs 下雨"两段式验证

## R — 原文依据

> "摆动指数好似积雨云，但是我们需要从蜡烛图技术得到最终的确认信号才能下结论。于是，我们仅仅把摆动指数的超买或超卖状态看作警告信号，这是一条线索，此外还要观察是否出现了蜡烛图形态提供的最终验证。"
>
> — 史蒂夫·尼森，《日本蜡烛图技术（第二版）》第十四章"蜡烛图与摆动指数"引言（上书第十四章，图 14.1 前，L2627）

---

## I — 方法论骨架 (Interpretation)

这个方法论解决一个问题：RSI、随机指数、MACD 这类摆动指数读数到底能不能当买卖指令？作者的答案是不能——它们只出"警告级"结论，方向指令必须由蜡烛图补发。

骨架分四层：

1. 摆动指数回答三件事：有没有背离（价格新高/新低而指标不跟随）、有没有超买超卖、有没有交叉（快线上穿/下穿慢线）。三要素是清点项，不是触发器。
2. 分工定位：摆动指数是"积雨云"（下雨概率升高的警告），蜡烛图反转形态是"下雨"（确认）。云彩再厚，没下雨就不动手。
3. 两段式流程：第一段指标给出警告 → 结论只能是"进入警戒"；第二段等同区蜡烛图反转信号出现 → 才升级为可执行的平仓/减仓/买入动作；没等到就只做保护性动作（上调止损），不抢跑。
4. 时序预期：蜡烛图信号常常领先西方指标约一周——蜡烛先动、指标殿后。等指标确认才动，往往错过最好价位；正确姿势是"指标定区域、蜡烛定时点"。

## A1 — 应用示例 (Application Example)

### 示例 1: 沃尔玛超买平多 + 斯伦贝谢超卖确认企稳
- **类型与来源**: 作者转述实盘判例（reported_case），上书第十四章·图 14.5 沃尔玛日线（RSI）、图 14.7 斯伦贝谢日线（随机指数）
- **问题/输入**: 权益市场多头为主的持仓者，问"行情涨了这么多、指标也高了，何时平仓"
- **方法论的使用**: 图 14.5——行情过度拉长 + 蜡烛线转折信号 + 摆动指数（超买/背离）验证三者在同区域出现 → 判定为"平仓退出或减磅"的好位置；图 14.7——斯伦贝谢 10 月一系列长下影线（企稳信号），同时随机指数接近 20% 超卖并发生看涨交叉 → 指标为蜡烛信号加权确认
- **结论**: 超买侧：指标警告 + 蜡烛转折 = 平多/减仓区；超卖侧：指标超卖 + 金叉增强看涨长下影线的意义
- **结果**: 图 14.5 为平仓判例（作者判读"此处就是平仓/减磅的好地方"）；图 14.7 后续走势未在引文内展开（未说明）

### 示例 2: 塔吉特——孕线→窗口→乌云盖顶→MACD 一图串
- **类型与来源**: reported_case，上书第十四章·图 14.8 塔吉特日线（MACD）
- **问题/输入**: 上涨途中孕线（3 月 16 日长白 + 次日小实体）后回落，随后 D 处（3 月 31 日—4 月 1 日）出现乌云盖顶
- **方法论的使用**: MACD 在乌云盖顶之后一周才给出看跌交叉（快线下穿信号线）；乌云盖顶高点成为阻挡，股价日内一度越过但收市回不到其上——阻挡完好
- **结论**: 蜡烛图乌云盖顶领先 MACD 约 1 周发出顶部信号；"积雨云"（MACD 死叉）殿后验证；阻挡有效性由收市价裁定
- **结果**: 乌云盖顶阻挡保持完好，股价受阻回落（书中判读）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 行情软件里看到 RSI 75/KDJ 高位/MACD 高位，拿不准"超买了要不要卖、要不要空"
2. 股价创新高（新低）而指标峰值没跟上，用户识别出（或听说了）"背离/顶背离/底背离"，问怎么操作
3. 想用 KDJ/随机指数金叉抄底，问"金叉了能不能买"
4. 列出"RSI+KDJ+MACD 三指标共振"当作买入理由，需要人纠正这是同源堆叠
5. 持仓浮盈，指标进入超买区，纠结"全卖还是减一点"

### 语言信号 (用户的话里出现这些就应激活)

- "RSI 超买了是不是要卖 / 是不是超买该跑了"（overbought, should I sell）
- "顶背离/底背离怎么看操作"（bearish/bullish divergence）
- "KDJ 金叉了能买吗 / 随机指数超卖"（golden cross, stochastics oversold）
- "MACD 死叉了要不要清仓"（MACD death cross）
- "三个指标都超卖了，是不是三重确认"（indicator confluence）

### 与相邻 skill 的区分

- 与 `divergence-index`（差异指数）的区别: 用户要"计算/标定收盘价对均线的偏离百分比、自测极端阈值" → 差异指数卡；问"RSI/KDJ/MACD 读数当不当卖、背离怎么办" → 本卡。差异指数是计算单元，本卡是验证纪律。
- 与 `signal-confluence`（信号汇聚）的区别: 汇聚卡清点整个价位区域的异源信号群（蜡烛×西方×量×价位结构）并评级；本卡只管"摆动指数 × 蜡烛图"这一对的两段式验证。全区域清点用汇聚卡，指标单项判读用本卡。
- 与 `ma-verification` 的区别: 均线回答"趋势/支撑阻挡在哪一侧"，是趋势过滤；摆动指数回答"力度是否衰竭"，是警告器。"站上 30 日线了吗"用均线卡。
- 与 `volume-confirmation` 的区别: 量能验证的是信号可信度加权（放量/缩量），不产生超买超卖读数；两者常在同一区域并行使用，但问句不同（"量跟上没有" vs "指标超买没有"）。

## E — 可执行步骤 (Execution)

**必需输入**: 标的价格序列（日线为主）+ 指标读数（用户提供，或由价格序列按下方公式自算）+ 当前持仓状态（持多/持空/空仓）。缺指标读数时先询问用户软件里的参数（如 RSI 14），不得静默猜参数。
**交付物与完成标准**: 两档结论之一——"警告级（等待清单 + 保护性动作）"或"确认级（执行动作）"；每条结论附等待清单（缺哪个条件）与所依据的读数。公式按书内口径执行并声明口径差异（见 G5 注记）。

**公式（书内口径，执行前先声明与所用软件的差异）**:

- RSI = 100 − 100/(1+RS)；RS =（14 日内收市价上涨幅度之和 ÷ 14）÷（14 日内收市价下跌幅度之和 ÷ 14）。注意：书内为**简单平均版**，多数软件用 Wilder 平滑版，两者数值不同，判定前声明用哪套（本卡默认按书内口径，若用户提供软件读数则以软件读数为准并标注）。
- 随机指数：%K =（当日收市 − N 日最低）÷（N 日最高 − N 日最低）× 100；慢 %K = 快 %K 的 3 期移动平均；%D = 慢 %K 的 3 期移动平均。（书内口径与部分软件惯例不同，按书内执行并声明。）
- MACD = EMA12 − EMA26；信号线 = MACD 的 EMA9；EMA 细节由软件标准补足。
- 阈值：RSI 70/30、随机指数 80/20 为常用值**非最优值**——须在自选标的的历史上自测极端值分布后声明（G1）。

执行步骤：

1. **三要素清点**
   - 把该标的当前可读的要素逐项登记：①背离（价格新高/新低 vs 指标峰谷是否配合；背离发生在超买卖区时技术意义更强）；②超买超卖（对照上一步声明的阈值）；③交叉（快线上穿/下穿慢线）。
   - 完成标准：三项各有"有/无"结论 + 读数数值。

2. **分工判定（判停分支 1）**
   - 三要素全无 → 输出"无摆动指数警告"，流程结束，不产生任何动作建议。
   - 有任一要素 → 结论只允许为**警告级**："积雨云聚集"。完成标准：输出语不含"卖出/买入"字样，只含"警戒/关注"。

3. **等待"下雨"（确认段）**
   - 在警告同价位（或同一区域）检查日线蜡烛图反转信号：顶部警戒 → 乌云盖顶/看跌吞没/黄昏星/流星线/长上影高浪线等；底部警戒 → 锤子线/看涨吞没/启明星/刺透等。
   - **判停分支 2**：蜡烛信号未出现 → 维持警告级，输出保护性动作（持多者上调止损/减磅可选），明确"不因超买清仓、不因超卖抄底"。
   - 蜡烛信号出现 → 升级为**确认级**：顶部 → 平多/减仓执行建议；底部 → 进入买进方向核对（步骤 4）。
   - 完成标准：结论档位（警告级/确认级）+ 等待清单（缺哪一项）+ 动作或明确的"不动"。

4. **买进方向三条件核对（随机指数专用）**
   - 三条件齐备才允许进入买入候选：%D ≤ 20（超卖）+ 已出现正面背离 + 慢 %K 上穿 %D。
   - **判停分支 3**：三条件不齐 → 买入流程判停，输出缺项。
   - 三条件齐 → **仍须等蜡烛图信号共振才买入**（两段式纪律不豁免）。
   - 完成标准：三条件逐项打勾 + 蜡烛共振信号名称，或缺项清单。

5. **时序校验与输出**
   - 若蜡烛信号已出现而指标尚未交叉/尚未回到中性 → 如实输出"蜡烛图领先约一周，指标殿后确认中"，不得因指标滞后否决已确认的蜡烛信号。
   - 输出契约：结论档位 + 依据读数表（指标数值 + 蜡烛形态名 + 价位）+ 动作清单或等待清单 + 口径声明（RSI 版本、阈值来源）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是指标计算/参数标定本身（"帮我算这只票的差异指数/偏离指数、定极端阈值"）→ 用 `divergence-index`。
- 用户在强单边趋势中问"指标钝化了怎么办"——本卡只能重申"超买可长期钝化"，趋势方向应交给均线卡/新价图卡，不要用摆动指数逆势开仓。
- 用户把多指标同读当"多重确认"来要背书 → 先转 `signal-confluence` 拒绝同源堆叠，再回本卡做两段式。

### 作者在书中警告的失败模式

- x16"积雨云还没下雨"：RSI/KDJ 一到 70/30 就清仓/做空。超买状态可以持续强化（强势股长期贴着超买走），摆动指数只提供"可能性升高"的警告，不具备时点资格。原文："我们仅仅把摆动指数的超买或超卖状态看作警告信号"。
- x34 同源堆叠幻觉：RSI+随机指数+MACD 本质同根（译者序"近亲结婚"），三者同时超卖只是同一份价格数据投三次票，不构成三重确认。

### 作者的盲点 / 时代局限

- 全书对摆动指数的论证停留在图例判读，无命中率/假信号率统计；样本为 1990–1994 年美国市场，牛市偏差未检验。
- 70/30、80/20 等阈值为常用值非最优值，作者要求自测但未给出测试方法论（样本、显著性、样本外验证）——自行标定时警惕数据挖掘与过拟合（G1）。
- 公式口径注记（G5）：书内 RSI 为简单平均版（非 Wilder 平滑）、随机指数的慢 %K/%D 结构与部分软件不同、MACD 的 EMA 细节由软件补足——三处均须在执行时声明口径，不得混用比对。

### A股制度适配（G2 缺口）

- 涨跌停制度下摆动指数钝化更显著（连续一字板使 14 日极值失真），阈值自测须包含涨跌停样本。
- "超买减仓/确认平多"在 T+1 下只能次日执行，隔夜跳空风险须在结论中提示。
- 蜡烛信号领先指标约一周的时序来自美股图例，A股适用性须自验，不作承诺。
