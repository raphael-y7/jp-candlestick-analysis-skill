## I — 方法自述

星线家族是**三根结构**的反转形态：一根长实体、中间一根小实体"星线"、再一根反向长实体——启明星看涨（下跌后）、黄昏星看跌（上涨后）。

两个反直觉要点：
1. **跳空可有可无**——理想形态里星线与前后实体之间有跳空，但作者经验是即使没有也不损效力，D2/D3 重叠照样成立（下书版本以"实体不触及"为标准并明示股市可以放宽，形态越接近标准越可靠）。
2. **决定性强弱的是第三根深入第一根实体的程度**——越深越强，"显著深入"以中点为准绳（书内无定量刻度，须声明所用准绳）。

变体分支：中间为十字线=十字启明/黄昏星；前后双跳空且影线互不接触=弃婴（极罕见极强）；单侧跳空十字出现在长白实体之下=崩盘十字星（大跌前兆，等确认）。

执行短板必须正视：三根形态要到第三根收市才完成，此时价格常已远离顶/底——登记形态极点为支撑/阻挡后，先核算风险报偿比或等回抽，不盲目追第一波。

## A1 — 应用示例

### 示例 1: 启明星完成即买 vs 等回撤
- **类型与来源**: reported_case，上书第五章图 5.5 美林证券日线
- **问题/输入**: 2 月初启明星形态，第三根长白收市即形态完成。
- **方法论的使用**: 完成时成本约 74 美元，距形态低点 65.50 美元 8.5 美元，止损又只能设在低点之下 → 报偿比差。改进法：等回落到形态低点构成的支撑区（65.50 附近）"小口小口"分批买，止损贴近入场。
- **结果**: 等回撤方案风险小；此后股价沿支撑线上行至约 90 美元（图注）。

### 示例 2: 黄昏星极点=阻挡+周线风险核算
- **类型与来源**: reported_case，上书第五章图 5.9 标普 500 / 图 5.10 罗杰通讯周线
- **问题/输入**: 标普 1 月初黄昏星；罗杰通讯周线黄昏星完成收市 31 美元、顶点 34 美元。
- **方法论的使用**: 标普——黄昏星顶部成为阻挡区，一周后 A 处上冲回测即以十字星耗尽能量；罗杰通讯——3 美元风险须对应"许许多倍"的目标才值得，否则等反弹回测 34 阻挡区再卖（两个时段后果然反弹 2 美元到位）。
- **结果**: 等回测方案兑现；周线方法可平移 A股周线。

## A2 — 触发场景 ★

### 用户会在什么情境下需要这张卡？

1. "跌了一大段后出现三根 K 线组合，像启明星，能买吗"。
2. "黄昏星/夜星出现了，是不是顶部"。
3. "弃婴形态/崩盘十字星是什么"。
4. "启明星第三根是大阳线，追进去止损太远怎么办"——完成价距极点过远的典型问句。
5. 用户把 3 根以上组合笼统称"启明星"——结构核对请求。

### 语言信号（中英双写）

- "启明星 / 晨星 / 黄昏星 / 夜星"（morning star, evening star）
- "三根 K 线 / 星线 / 中间那根小实体"（three-bar pattern, star candle）
- "弃婴 / 崩盘十字星"（abandoned baby）
- "没跳空还算吗"（gap optional）

### 与相邻能力卡的区分

- 与 `signal-context-filter` 的区别：形态成立后是否行动、方向分派由 C01；本卡自带"完成价距极点过远→先算比值"的强制分支。
- 与 `stop-reward-risk-skill` 的区别：形态极点=止损锚由本卡登记，完整核算在 C20（可可启明星案例即两卡联动的书内判例）。
- 与 `nonstandard-synthetic-candle` 的区别：缺跳空、实体重叠的"近似启明星"按两书弹性规则仍可成立，但接近度不足时转 C22 处理。
- 与 `doji-context` 的区别：十字线单独出现归 C09；作为星线家族中间一根才归本卡。

## E — 执行步骤

**必需输入**: 三根（或三组）OHLC + 趋势方向。缺趋势方向 → 询问（启明=跌后、黄昏=涨后）。
**交付物与完成标准**: 形态成立与否 + 强度档（深入程度）+ 极点登记 + 风险报偿比核算提示。

1. **三根结构判读**
   - 长实体（D1）+ 小实体星线（D2）+ 反向长实体（D3）；此前趋势匹配方向。
   - 跳空可有可无：上书表 A 要求 D2 跳空成星线、正文允许弹性；下书以"实体不触及"为标准并明示股市弹性——**两版并列声明**，形态越接近标准越可靠。
   - 完成标准：三根结构逐根描述+跳空状态记录。

2. **决定性判据与强度档**
   - D3 深入 D1 实体的程度是决定性因素，越深越强（L911 逐字）；"显著深入"以中点为准绳——深度刻度无定量标准，本次声明所用准绳（G1）。
   - 增强要素：D1 量小 D3 量大；星线为十字/高浪线=加重。
   - 完成标准：写出中点数值与 D3 收市价的比较+强度档（强/中/弱）。

3. **变体分支**
   - D2 为十字 → 十字启明/黄昏星。
   - 前后双跳空且影线互不接触 → 弃婴（极罕见极强，仍按收市价确认）。
   - 单侧跳空十字于长白实体之下 → 崩盘十字星（大跌前兆，等下一时段确认）。
   - 三星形态（三根连续十字）→ 全书唯一单一来源收录形态，**采信度最低**——识别须最严格核验（三根全为真十字+趋势环境），否则不认。
   - 完成标准：变体命名+分支依据。

4. **极点登记与执行分支**
   - 登记形态极点（启明星低点=支撑、黄昏星高点=阻挡）；收市穿越极点=失效确认。
   - **判停分支**：完成价距极点过远（如 D3 为长实体）→ 先转 `stop-reward-risk-skill` 核算比值，或等回抽极点区，不直接追价。
   - 完成标准：极点价位+失效价+执行分支三选一（直接行动 / 等回抽 / 核算比值）。

## B — 边界 ★

### 不要在以下情况使用此卡
- 形态完成时价格已远离极点仍市价追单——确认滞后是结构性的（x25）。
- 把崩盘十字星/弃婴的"极强"预期当成必然幅度——蜡烛图不预测幅度（x35）。
- 三星形态不做最严格核验就认定——单一来源收录，采信度最低。

### 书中警告的失败模式
- x25（确认滞后）：图 5.5 / 图 5.10 / 43.25 平台三源同证——三根形态天然滞后 2-3 个时段，"越确认越远离极点"；解法是等回抽（不保证出现）、以极点为止损锚重算比值、或放弃。
- x03（报偿比倒挂）：可可启明星 36 风险/15 收益——形态标准与交易价值是两回事；该反例正是本卡执行分支存在的理由。

### 作者盲点（阶段 0 批判）
- 无统计回测（G3）；1990s 美国样本；"显著深入"无定量刻度（G1）；"跳空可有可无"的弹性幅度无边界——书内以"越接近标准越可靠"收口，须自行声明接近度标准。

### A股制度适配注意
- T+1：等回抽方案可实现（卖出资金可用与买入次日可卖分离）；追价买入后若次日跌破极点，止损当日可卖（已持有）。
- 涨跌停：D3 一字涨停的启明星——收市深度条件自动满足但无法买入；跌停黄昏星同理无法卖出——执行分支须核对可成交性。
- 停牌：D1-D3 之间夹停牌则"三根"的时间连续性断裂，降级为观察（原书未讨论，A股适配约定）。
