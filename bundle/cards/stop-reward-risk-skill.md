# 止损位设定与风险报偿比核算（"先算后做"）

## R — 原文依据

> "请记住，在某个蜡烛图形态完成时，除非你判定风险与回报比率很诱人，否则请放弃交易。有句日本俗语所说的极是：'勇士的潜能是一张拉满的弓，但关键在于放弦的时机。'放弦的时机就取决于对风险与收益比率的研判。"
>
> — 史蒂夫·尼森，《日本蜡烛图技术新解》第 4 章"风险与收益的权衡"（下书第 4 章，L5237）

> 配套原则（上书第四章，L759/L771）：止损应在初始交易时同时设定——"要把止损当作这门生意的成本"；上书第四章图 4.8 前（L629）："应该总是存在某个价位，表明我们是错误的。"

---

## I — 方法论骨架 (Interpretation)

这个方法论把"看到一个漂亮形态就想下单"的冲动，改造成一道算术闸门：任何一笔候选交易，在按下单键之前必须先写齐三个价格——入场价、止损价、目标价——再算一个比值。

止损价不许拍脑袋：它由形态与价位结构**客观给定**（做空者的止损在乌云盖顶/空头吞噬高点上方，做多者的止损在锤子线/启明星低点下方，以此类推），一律以收市价穿越为准。目标价不许凭感觉：蜡烛图不给目标，必须由西方工具（旧支撑转阻力、百分比回撤、箱体/趋势线等）供给，且目标方法一旦选定就固定下来。

风险 = 入场价 − 止损价；报偿 = 目标价 − 入场价；比值不诱人就放弃，等回调到贴近止损的位置再入（拉弓等放弦）。但作者同时提醒另一面：许多时候市场并不回调，"等更好入场价"可能永远等不到——权衡必须事前做，不做事后悔。

三条纪律贯穿始终：初始交易时同时设止损（此时态度最客观）；止损是这门生意的成本（为赢下战争输掉几场战斗是常态）；总有某个价位证明你是错的——收市到达它就认错离场，不辩论。

## A1 — 应用示例 (Application Example)

### 示例 1: 可可启明星——全书唯一入场前完整演算（主案例）
- **类型与来源**: 作者转述实盘判例（reported_case），下书第 4 章·图 4-6"风险收益比——1992 年 3 月可可"日线
- **问题/输入**: 1 月 10 日启明星形态完成，收市 1205 美分，"此时的价位是否值得买入？"
- **方法论的使用**: ①目标 = 极性转换：上一年 11 月下旬 1220 美分旧支撑转压力，预计反弹至 1220 阻力区；②止损 = 启明星低点 1169 美分下方，未来某收市价低于该点即离场；③核算：风险 = 1205 − 1169 = 36 美分，报偿 = 1220 − 1205 = 15 美分
- **结论**: 36 风险 vs 15 报偿，"无论怎么解释，这个收益风险比率都太低" → 放弃交易，"不要在某个蜡烛图形态出现之时就急于下单交易"
- **结果**: 行情其后反弹至约 1230（一度触及目标区）后再度跌至 1100 一带——信号"没错"，交易仍是赔本买卖（图 4-6 图注）。演算步骤 100% 可迁移 A股（单位换成本币即可）

### 示例 2: 乌云盖顶的机械止损（止损位的客观给定）
- **类型与来源**: reported_case，下书第 4 章·图 4-1（乌云盖顶止损点）
- **问题/输入**: 依据乌云盖顶形态放空，止损设哪？
- **方法论的使用**: 止损客观定在形态最高点上方；第 8 天市场跳空开窗口、收市价高出压力区高点 → 信号翻转，空头必须认错
- **结论**: 形态高点 = 机械止损位，收市价穿越 = 认错离场；"价格已上穿止损位还幻想回落"是一厢情愿，"倚靠白云的梯子，只会导致坠落"
- **结果**: 第 8 天止损触发，趋势判定翻多（其后上涨）

### 示例 3: 沃尔玛锤子线——同一形态两种入场的比值差（次级）
- **类型与来源**: reported_case，上书第四章·图 4.7 沃尔玛日线
- **问题/输入**: 经典锤子线收市约 48 美元，低点约 43 美元。甲在收市价追买，乙等次日回抽到下影线低端的潜在支撑区再买
- **方法论的使用**: 甲风险 ≈ 5 美元，次日低开 44.50 即浮亏 3.5 美元；乙建仓点贴近止损位，风险大幅缩小
- **结论**: 先算后做 + 等回抽入场改善比值；但作者明示"许多时候市场并不回调"——两种方案须事前权衡
- **结果**: 甲次日即深度浮亏；乙买入后股价自支撑区上冲（两人最终盈亏书中未完整交代，未说明）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户看中一个形态/信号准备下单，问"止损设哪？这单值不值得做？"——任何买入/卖出候选定型之后、下单之前的最后核算
2. 用户持仓浮亏，问"该不该止损/要不要扛一下"——需要用"哪个价位证明我是错的"重新核算
3. 用户报出买卖点和目标价，问"帮我算算风险收益比/盈亏比划不划算"
4. 用户在两个候选入场（现价追 vs 等回抽）之间犹豫，需要比较两者的比值差异
5. 用户发现自己的持仓说不出"错了在哪里离场、对了到哪里兑现"两个具体价位

### 语言信号 (用户的话里出现这些就应激活)

- "止损设在哪 / 止损位怎么定"（where to place the stop-loss）
- "风险报偿比 / 盈亏比 / 风险收益比 帮我算一下"（risk-reward ratio, compute）
- "这单值不值得做 / 划不划算"（is this trade worth taking）
- "该不该止损 / 被套了要不要割"（should I cut the loss）
- "先算后做 / 拉弓等放弦"（先算后做 as a named rule）

### 与相邻 skill 的区分

- 与 `price-target-retracement-skill` 的区别: 用户只问"目标价看到哪 / 回撤到哪了"（算分子）→ 目标测算卡；问"这单该不该做"（组装分子分母并裁决）→ 本卡。本卡的目标位输入通常由目标测算卡供给。
- 与 `discipline-falsification` 的区别: 本卡管**入场前**的比值核算与做/不做裁决；纪律卡管**持仓中**的证伪价维护与到价改判。买单生成时的止损纪律声明衔接纪律卡。
- 与 `support-resistance-system-skill` 的区别: 支撑阻挡卡供给止损/目标的候选价位（破低反涨四件套自带完整价位组）；本卡不自己找价位，只核算与裁决。
- 与 `signal-context-filter` 的区别: 位置过滤决定信号"有没有资格"，比值核算决定交易"值不值得"——先过位置闸门，再算比值。

- 混合请求（同时问仓位管理/资金分配与止损）时：只执行止损位设定与风险报偿比核算部分，其余明确声明超出范围并转介，不整体拒答。

## E — 可执行步骤 (Execution)

**必需输入**: ①候选入场（形态名 + 完成价/计划入场价，本币）；②止损候选位（或形态信息，由步骤 1 推导）；③目标候选位（或声明"请求目标测算/支撑阻挡卡供给"）。缺入场价或形态信息时先询问，不得静默猜值。
**交付物与完成标准**: 风险额、报偿额、比值（保留两位小数）+ "交易 / 放弃"结论 + 止损纪律 if-then 声明。所有价差用同一币种与同一单位，除法保留两位；书内未规定比值合格线，合格线由使用者自定义并声明（G1，本卡默认在输出中留空待用户声明）。

1. **止损位客观化**
   - 按形态与结构对照下表取止损锚（一律以**收市价**穿越为准，盘中穿越不算）：
     - 做空：乌云盖顶 / 空头吞噬 / 黄昏星 → 形态**高点上方**
     - 做多：锤子线 / 启明星 / 看涨吞没 → 形态（或形态低点）**下方**
     - 做多：向上窗口（缺口）支撑买入 → **缺口底部下方**（以周收盘计按周线口径）
     - 沿趋势线持仓 → **趋势线下方**
     - 破低反涨（假突破收复）买入 → **最近低点**（收市价口径）
   - 完成标准：写出一个具体价格 + 它对应的形态/结构名。

2. **目标位供给**
   - 目标来自西方工具：旧支撑转阻力（极性转换）、百分比回撤位、箱体/对等运动/旗形/三角形测算、上方下降阻挡线等（由 price-target-retracement-skill / support-resistance-system-skill 卡供给）。
   - 目标方法因人而异（同一信号用极性转换目标与 38% 回撤目标结局可相反），须**固定规则**并在输出中声明本次用的哪套。
   - 完成标准：写出一个具体目标价 + 方法名。蜡烛图本身不提供目标——无目标则比值分子缺失，不得虚构幅度（x35）。

3. **比值核算**
   - 风险 = |入场价 − 止损价|；报偿 = |目标价 − 入场价|；比值 = 报偿 ÷ 风险。
   - **判停分支 1**：比值不诱人（低于用户声明的合格线）且没有可改善入场价的方案 → 判停"放弃交易"，不为该信号继续寻找买入理由。
   - 改善方案（可选）：等回抽至形态低点/支撑区再入，使止损贴近入场价（示例 3 的乙方案）；同时如实提示"许多时候市场并不回调"，不保证回抽出现。
   - 完成标准：三个数字 + 一个比值 + 与合格线的比较结论。

4. **纪律绑定（if-then 声明）**
   - 入场即设止损；止损**只上调、不下调**；收市跌破止损价 → 认错离场（转 discipline-falsification 卡维护）。
   - 若市场处于长阴长阳交错的剧烈震荡期 → 不核算直接停手退出观望（"像 8 级地震"，x24）。
   - 完成标准：输出末尾附 if-then 一句话预案（"若收市低于 X，则离场"）。

5. **输出契约**
   - 表格字段：入场价 / 止损价（锚名）/ 目标价（方法名）/ 风险额 / 报偿额 / 比值 / 结论（交易·放弃·等回抽）/ if-then 预案 / 合格线声明。
   - 单位与容差：同一币种同单位；比值保留两位小数；价位不必四舍五入到整数（A股用两位小数）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户还没有候选信号/入场想法，只想问"现在大盘怎么看"——无核算对象，先走形态识别与位置过滤。
- 用户要的是仓位管理（凯利、固定比例、金字塔加仓）——书内未提供，本卡只算单笔比值，不输出仓位算法。
- 用户要求预测涨跌幅度——报偿比的分子必须由已声明的目标工具供给，无出处的幅度预期是虚构（x35"不可缘木求鱼"）。

### 作者在书中警告的失败模式

- x03（图 4-6 可可）：36 风险 / 15 报偿仍急于下单——形态完成价 ≠ 最优入场价，三根形态完成时价格常已走出大段反弹，止损被拉远、目标近在眼前（注意原书单位为美分）。这是"先算后做"最直接的算术反例。
- x04（图 4.7 交易者甲）：收市瞬间追高，次日跳空低开即深套；同时警惕另一面——等回调也可能永远等不到，两种入场须事前权衡。
- x21：只装入场信号不装离场条件；"没有止损的程序是非常危险的操作"。DISCIPLINE 守则的 Stops 与 If-then 条目原文在案。
- x22（压路机比喻）：迎着趋势举牌"方向错了"——即便预见正确，也可能在兑现前破产（"正确但破产"）。
- x24：长阴长阳交错的震荡期强行交易 = "无谓的牺牲"——比值计算的基础（可依赖的支撑阻挡）此时失效，正确动作是停手。
- x25：三根形态（启明星/黄昏星/乌云盖顶）确认滞后 2-3 个时段，完成时入场点已经恶化——解法是等回抽、重算比值或放弃，不是抱怨信号。

### 作者的盲点 / 时代局限

- 比值"合格线"书内从未给出（未提供 2:1/3:1 之类的参考值），须自定义声明；无任何统计回测支持"先算后做"能提升净收益，这是经验纪律而非检验过的规则（G1/G3）。
- 案例由作者自选，失败案例不入统计呈现。

### A股制度适配（G2 缺口）

- T+1：当日买入不能当日卖出，"收市跌破止损价认错"实际执行在次日开盘——隔夜跳空风险须计入风险额（保守做法：按止损价与次日可能的低开估一个区间）。
- 涨跌停：跌停封板时止损单可能无法成交，收市价锚 + 次日竞价离场是本土变形，须在 if-then 中写明。
- 原书案例为期货/美股（单位为美分/美元），迁移 A股只搬算法与纪律，不搬绝对价位与市场结构（卖空在 A股个人投资者基本不可得——本书空头示例对 A股用户主要用于"减仓/离场"决策的方向性参考）。
