# 决策规则速查 — 日本蜡烛图技术（第二版+新解）合并蒸馏

| 能力 | 一句话规则 |
|---|---|
| 位置背景过滤与信号取舍决策流程 | 形态的位置比形态本身更重要——先确认有趋势可反转，再过位置四要素；顺主要趋势才开新仓，逆向信号只用于减仓保护。 |
| 蜡烛图数据质量与确认口径门 | 一切形态判读前先过三查——真实开盘价、收市价确认锚（盘中穿越不算）、判据版本选一版记录并全程一致。 |
| 单根K线状态读数与开盘先行判据 | 长实体（≥前日实体3倍）读控制权、影线读环境拒绝、实体中点与底顶登记价位带、次日开盘相对前实体中点验短期强弱。 |
| 交易量验证清单与积聚/派发矩阵 | 量只做相对比较——先核形态的理想量分布给信号加权，再按"低价区放量呆滞=积聚、高价区放量停滞=派发"定位；量缩新高只减分不定罪。 |
| 伞形线族判定、验证与交易执行 | 小实体居上端+长下影按先前趋势定名（跌后锤子线看涨、涨后上吊线看跌）；上吊线/倒锤子线必须次日收市越过实体才生效；锤子线止损在其低点下方（收市价口径）。 |
| 双线反转形态判定（含强度分级与两市场口径） | 吞没须实体覆盖+颜色相反+先前趋势；乌云盖顶未过中点不算完成（刺透必须过中点）；收市上穿形态高点=信号失效，形态高低点登记为阻力/支撑。 |
| 孕线族与次级反转信号处理 | 孕线小实体居中点才谈反转、居上下端是横盘预告；反击线/平头/三只乌鸦等弱信号须共振才行动并一律登记失效价。 |
| 星线家族三根结构判定 | 三根结构（长实体+星线+反向长实体）成立与否看第三根深入第一根实体的程度（跳空可有可无）；完成价距极点过远则先算风险报偿比或等回抽。 |
| 十字线环境判定与动作分档 | 单根十字线只把趋势下调一档（上升→上升或中性），须第二信号才改判下降；长白线后十字线取双高点为阻挡、收市价判突破。 |
| 迭创新高（低）计数与超买超卖预警 | 收盘价连续 8–10（自测阈值）次刷新极值即超买（超卖）警戒——停止顺势加仓、准备变现；横盘或大幅修正后重新计数，反向动作仍须等蜡烛图信号。 |
| 窗口（跳空）判定、支撑管理与趋势终结规则 | 影线互不重叠才算窗口；整个窗口是支撑/阻挡，收市封闭=原趋势终结；数满三窗只做保护，趋势持续到最后一个窗口被收市价关闭。 |
| 持续形态判定与变体硬纪律 | 持续形态确认趋势续航与加仓位；前方受阻/停顿只许平多保护、禁止开空；完成价离首根极点过远先算风险报偿比再追。 |
| 长期形态识别与确认 | 大级别顶底 = 三次试探同一水平 + 最后一峰蜡烛信号确认 + 收市破颈线；颈线破位即按极性转换登记新阻挡/支撑。 |
| 相互验证体系与信号汇聚清点 | 同一价位清点异源信号（同家系只计一票）：越多越重要，"重要"以上才动持仓；同源指标堆叠不算验证。 |
| 支撑阻挡体系与假突破反向交易 | 收市破位又收复=假突破反向（Spring/Upthrust）：入场、止损=最近极点（收市价口径）、双目标；旧支撑收市破位即登记为新阻挡。 |
| 百分比回撤与价格目标测算 | 回撤位必须等蜡烛信号验证（不在裸位买卖）；目标=几何投影，只用于平仓不用于开仓，收市回箱体即作废。 |
| 移动平均线用法与"均线×蜡烛图"验证纪律 | 不裸按均线交易：回落至均线须蜡烛信号验证支撑才买；均线压制下一切底部信号降级，等收市升破均线。 |
| 差异指数/偏离指数计算与高低价区标定 | 差异指数=（收−均线）/均线：极端读数（阈值按标的自测，±10% 起步）只是狂热提示，行动须等蜡烛图信号确认。 |
| 摆动指数三要素与"积雨云 vs 下雨"两段式验证 | 摆动指数只出警告级结论（积雨云），等同区域蜡烛图反转信号出现（下雨）才升级为执行动作，否则只做保护性动作。 |
| 止损位设定与风险报偿比核算（"先算后做"） | 下单前先写齐入场价、客观止损价（形态给定）、目标价（西方工具供给），风险÷报偿不诱人就放弃——拉弓等放弦。 |
| 交易纪律守则与预判可证伪化（DISCIPLINE + 市场变色龙） | 预判必须绑定"收市到达即认错"的证伪价（多重阻力叠加），到价强制改判、未到价维持原判，做紧跟市场的变色龙。 |
| 非标准形态三处理法与合成蜡烛线四步法 | 形态差一点不满足判据时三选一：按标准判读等次日确认、关键位置加持直接采信、合成蜡烛四步法（首开+全组最高最低+末收）单根法则互证。 |
| 三线反向突破图画法与转向线交易 | 创新高画白线、创新低画黑线、区间内不画线；三根连续同色线后须反向超越（非触摸）其极点才画转向线——转向线即平仓触发。 |
| 砖形图画法与白砖买/黑砖卖 | 预设砖值，收盘价自前砖顶/底出发涨跌达到或超过砖值才加砖（不足不显示、砖等高）；白砖买、黑砖卖，横盘拉锯须降频。 |
| 钥匙图画法与阴阳转换交易体系 | 反向变动达转向值才右移画线；细线穿越前高（肩）变粗（阳）、粗线跌破前低（腰）变细（阴）——见阳买、见阴卖，肩腰读势，抓主段不逃顶。 |
| 新价图与蜡烛图的分工流水线（宏观定向 + 微观择时） | 新价图定方向（连续白线=牛、转向线=警报），蜡烛图只在判定方向内找时机（逆势信号仅平仓保护），转向线/阴阳转换触发平仓。 |
| 消息反应核对与资料采信元规则（参考级） | 消息公布后不立即交易，观察市场反应——该涨不涨即绷紧警惕之弦（看跌线索），登记利好日低点为利空试探位、收市跌破即确认。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
