# 长期形态识别与确认

## R — 原文依据

> "如果市场先后三次均从某一个高价位上回落下来，或者市场对某一个高价位向上进行了三次尝试，但都失败了，那么一个三山顶部形态就形成了。在三山顶部形态的最后一座山的最高点，还应当出现一种看跌的蜡烛图指标……对三山顶部形态做出确认。"
>
> — 上书《日本蜡烛图技术（第二版）》第六章"三山顶部形态"（图 6.35；颈线与极性转换另见图 6.41–6.44）

---

## I — 方法自述

大级别顶底（数月、周线尺度）在蜡烛图里对应一组日本形态: 三山/三川 = 三重顶/底，三尊 = 头肩形（中间峰最高），圆形顶/平底锅底 = 圆弧形，塔形顶底 = 长实体包夹整固区。共同判读纪律有三条:

1. "三次试探同一水平附近"即可成立，三峰（谷）不必等高——这是结构弹性，别拿尺子量。
2. 最后一峰（谷）必须出现蜡烛图信号（十字线、流星线、乌云盖顶、向下窗口等）确认，没有确认信号就不判反转——这是本卡与"看图数山峰"的根本区别。
3. 颈线（三尊）或形态极点被收市价击穿后，按极性转换登记为新阻挡/支撑，破位回抽就是二次确认位。

圆弧族有一条独有硬规则: 平底锅底必须以窗口（跳空，再小也算数）确认——这是它强于普通圆形底的原因。塔形不需要跳空，完成偏晚，只适合长线视角。

## A1 — 应用示例

### 示例 1: 英特尔周线三山顶部——最后一峰由流星线 + 向下跳空确认
- **类型与来源**: reported_case，上书第六章·图 6.40 英特尔 周蜡烛线图
- **问题/输入**: 英特尔周线三峰（A 约 71、B 约 74、C 约 76 美元）算不算主要顶？
- **方法论的使用**: C 峰最后两个时段仅以极短实体上行（"不安的症状"），76 美元留下一根流星线——最后一峰获蜡烛信号；真正的确认是流星线之后的向下跳空（窗口）。
- **结论**: 三山顶部确认成立。
- **结果**: 76 美元见顶后行情急落至 44 美元附近（图 6.40 图注）。

### 示例 2: 美元日元三尊与英镑倒三尊——颈线破位与极性转换的联动
- **类型与来源**: reported_case，上书第六章·图 6.41 美元兑日元（三尊顶）、图 6.43 英镑兑美元（倒三尊）
- **问题/输入**: 破颈线之后颈线还能怎么用？
- **方法论的使用**: 美元日元 8 月 19 日收市跌破颈线 → 颈线立即转为阻挡；8 月 21 日起四次反弹全部受阻于颈线下方并留看跌长影线。英镑 1.63 一线的原阻挡被长阳收市突破 → 转为新支撑。
- **结论**: "颈线破位 → 极性转换 → 回抽确认"链条成立。
- **结果**: 美元日元反弹全部受阻后继续下跌；英镑 1.63 此后作支撑使用（两书叙述）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 周线/月线上疑似"头肩顶/双顶/三重顶"，问大级别是不是见顶。
2. 长线持仓浮盈较大，问要不要在大级别顶部清仓、什么条件算确认。
3. 颈线破位后问"回抽怎么办、还能不能追减/跟进"。
4. 长期横盘后缓慢圆弧走势，问是不是"锅底"可以左侧布局。

### 语言信号 (用户的话里出现这些就应激活)

- "头肩顶 / 头肩底 / head and shoulders"、"三重顶 / 三重底 / triple top"
- "颈线 / neckline"、"双顶 / 双底 / double top"
- "圆弧底 / 锅底 / rounding bottom / saucer"
- "三山 / 三尊 / 大级别顶 / 周线级别顶底"

### 与相邻 skill 的区分

- 与 `support-resistance-system-skill`（C15）的区别: 本卡负责"识别大形态 + 最后一峰确认 + 破颈线"这一步；颈线/极点破位后的价位登记、回抽交易细节归 C15 的极性转换。
- 与 `two-line-reversal`（C06）的区别: 流星线、乌云盖顶等日线级双根/单根反转形态是"最后一峰确认信号"的构成件，其自身判定在 C06/C03；本卡管数月结构。
- 与 `signal-context-filter`（C01）的区别: 本卡输出的破位动作（减仓/清仓/观望）仍按 C01 的方向分派原则执行——大形态不豁免"逆势信号只用于保护"的总闸门。

## E — 执行步骤

**必需输入**: 周线（或日线）数月结构的高低点序列 + 关键水平（峰/谷/颈线候选）；个股须先复权。
**交付物与完成标准**: 形态定名 + 确认状态（未确认/最后一峰已确认/颈线已破）+ 颈线与形态极点登记 + 破位动作建议；每个判定给出价位与日期。

1. **结构圈定**
   - 找"三次上攻（下探）同一水平附近"的峰谷序列，不必等高。
   - 完成标准: 三次试探的价位与日期列出。
   - 判停: 只有两峰 → 按"双重顶/底"处理，确认条件 = 收市破两峰间低点（高点）；不足两次完整试探 → 不判形态。

2. **最后一峰确认核查（判停点）**
   - 最后一峰（谷）处必须有蜡烛图信号: 十字线/流星线/乌云盖顶/向下窗口/启明星等。
   - 判停: 无确认信号 → 输出"形态存疑，仅记录，不判反转"。
   - 完成标准: 确认信号名称与日期登记。

3. **颈线与破位**
   - 三尊颈线 = 两谷（峰）连线；只有收市价破颈线才算破位（盘中不算，周线按周五收市）。
   - 完成标准: 颈线价位 + 破位日收市价。

4. **极性转换登记**
   - 收市破颈线 → 颈线登记为新阻挡（顶形态）/新支撑（底形态）；反弹（回踩）至该区 = 二次确认/逃命位，须与蜡烛信号互验（登记细节转 C15）。
   - 完成标准: 新阻挡/支撑价位入登记表。

5. **圆弧族分支**
   - 圆形顶/平底锅底必须以窗口确认——跳空再小（几美分/几分钱）也算数；平底锅底强于普通圆形底。
   - 判停: 圆弧末端无窗口 → 输出"圆形底/顶（弱），待确认"。

6. **塔形分支**
   - 长实体—整固—反向长实体，不需跳空；完成偏晚 → 只建议长线视角使用并声明滞后。

## B — 边界

### 不要在以下情况使用此 skill

- 日线尺度硬套三山/三尊: 数周内的三个高点更多是箱体或 C07 的弱信号族，本卡要求数月结构。
- 看到"三个高点"就喊三重顶而不等最后一峰的蜡烛信号确认——"看形状不看来路"的位置错误在长期形态上的翻版。
- 破颈线后立即把颈线当"铁支撑/铁阻挡"——须收市价确认，且回抽须蜡烛信号互验。

### 作者在书中警告的失败模式

- 最后一峰必须确认（R 段原句）——未经确认的三峰只是结构猜想。
- 圆弧族窗口确认是两书一致的硬规则: 无窗口的"平底锅"只算普通圆形底（效力更弱）。

### 作者的盲点 / 时代局限

- 长期形态判读的事后拟合风险最高: 作者自选图例、失败样本不入统计（阶段 0 批判——案例选择偏差）。
- "三次试探"没有时间跨度与重合度的量化标准（G1 结构性弹性判据，须声明）；全书无统计回测。

### A股制度适配（G2 缺口）

- 个股受题材与涨跌停影响，周线长期形态常被资金行为扭曲——指数（如沪深 300 周线）比个股更适合本卡。
- A股周线收市 = 周五（C02 口径）。
- 除权除息必须先复权再画形态，否则峰谷与颈线价位失真（原书未讨论，本土缺口）。
