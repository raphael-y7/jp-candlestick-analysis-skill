# 消息反应核对与资料采信元规则（参考级）

## R — 原文依据

> "当你听见利空或利多消息时，不要依此进行交易。不要在消息放出后，立即开始交易，比较安全的做法是，判断市场对于该事件的反应，然后决定自己的行为。"
>
> — 史蒂夫·尼森，《日本蜡烛图技术新解》第 2 章"三猿金钱录·不听邪"（下书第 2 章，L4054–4056，图 2-1）

---

## I — 方法论骨架 (Interpretation)

这是全书的参考级单元：大部分内容是叙述与警示，唯一可检验执行的是"消息反应核对"——

**核心动作**：重大消息（利好或利空）公布后，不依消息本身立即交易，而是观察**市场对消息的反应**。"该涨不涨"是最有操作价值的反应：利好落地价格却停滞（尤其停在前高下方），说明供给压倒消息，绷紧警惕之弦、视为看跌线索；此时登记利好日低点为利空试探位，收市跌破即确认信号。作者引用的判例是 1990 年 8 月中东战争爆发，黄金停滞于 425 美元前高下方，两个月内回落至 360 附近——"市场波动中重要的不是事件本身，而是对事件的人性反应"。

**三条辅助元规则**（姿态性，无可检验输出）：①三猿心法（不见邪/不听邪/不言邪——趋势过热时不追、不听消息下单、不四处宣扬自己的计划）；②双来源采信——一项说法至少要两个独立信息来源证实才收录采信（作者自己为三星形态破例，恰是采信度警示）；③远离传言——对传闻驱动的个股不参与。

**本卡的姿态**：它是纪律卡 DISCIPLINE 中"E——检查市场对消息的反应"一条的展开，也是整个 Skill 采信标准（"数字 3、8~10、±10% 皆是文化参数须自测"）的元规则出处。

## A1 — 应用示例 (Application Example)

### 示例 1: 黄金 425"该涨不涨"（叙述素材，非完整案例）
- **类型与来源**: 叙述性判例（reported_case，作者转述图 2-1），下书第 2 章·图 2-1"观察市场对基本消息的反应——黄金市场（1990 年 12 月，日线）"
- **问题/输入**: 1990 年 8 月初伊拉克战争爆发（重大利好利多黄金），金价如何反应？
- **方法论的使用**: 不依"战争 = 买黄金"立即交易；观察反应——金价停滞于 425 美元（当年早些时候的前高）之下无法突破
- **结论**: "该涨不涨"→ 绷紧警惕之弦、视为看跌线索；受阻 425 后登记利空试探逻辑
- **结果**: 黄金此后两个月回落到中东危机前的 360 美元附近（书中叙述；此为叙事佐证，未给出可复算的完整规则流程）

### 示例 2: 消息反应核对演算（合成演练，明确标注）
- **类型与来源**: 原书未提供个股级可复算案例，以下为**明确标注的合成演练**（按"该涨不涨"规则可复算）
- **问题/输入**: 某股重大利好公告，次日高开 3%，当日收阴（收市价低于昨日收市）
- **方法论的使用**: ①不因利好买入；②反应核对 = 利好 + 滞涨收阴 → "该涨不涨" → 看跌线索；③登记公告日低点为利空试探位，收市跌破 → 信号确认
- **结论**: 输出"绷紧警惕 + 试探位已登记"，不产生买入动作
- **结果**: 演算自洽输出；不虚构后续行情

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户拿着一条消息（利好/利空/传闻）问"该不该据此买卖"——需要"先看反应、后定行为"的核对流程
2. 用户观察到"利好出尽不涨/利空出尽不跌"的现象，问这意味着什么、怎么操作
3. 用户问"这条消息/这个说法可信吗 / 只有一处提到"——双来源采信核对
4. 用户被荐股群/传闻驱动的个股吸引——远离传言的回避性准则

### 语言信号 (用户的话里出现这些就应激活)

- "利好出尽是不是要卖 / 利好怎么还跌"（sell the news, good news but price falls）
- "该涨不涨 / 该跌不跌"（failed to rally on good news）
- "这条消息可信吗 / 只有一个来源"（single source, verify）
- "传闻股 / 荐股群说的要不要跟"（rumor-driven stock）

### 与相邻 skill 的区分

- 与 `discipline-falsification` 的区别: 消息反应核对是纪律卡 DISCIPLINE 中 E 项的展开；纪律卡管全部十条与证伪改判机制，本卡只管"消息 × 市场反应"这一对关系与采信元规则。用户问"我的预判被破了怎么办"→ 纪律卡。
- 与基本面分析的区别: 本卡不判断消息真伪、不解读业绩与政策含义——只核对市场的价格反应。用户要业绩/政策解读时明确声明超出范围。
- 与 `signal-context-filter` 的区别: 位置过滤处理的是技术信号语境；本卡处理的是消息事件语境，输出的是"警惕级别"而非信号取舍。

## E — 可执行步骤 (Execution)

**必需输入**: 消息事件（类型：利好/利空/传闻 + 公布时点）+ 事件前后若干交易时段的价格数据（开高低收）。
**交付物与完成标准**: 反应核对结论（该涨不涨 / 该跌不跌 / 正常反应 三选一）+ 利空试探位（若适用）+ 采信声明（来源数）。本卡输出为**警惕级**结论，不产生方向性买卖指令。

1. **事件登记**
   - 写明消息内容、性质（利好/利空/传闻）、公布时点（盘前/盘中/盘后）。
   - 完成标准：事件三元组（内容/性质/时点）登记完毕。
2. **反应观察窗口**
   - 不依消息立即交易；观察公布后 1~3 个交易时段的价格反应（高开/低开 + 收市相对前收市的方向 + 是否突破/跌破关键价位）。
   - 完成标准：窗口内逐日反应数据表（日期/开/收/相对前收市/相对关键位）。
3. **反应核对（唯一可执行判据）**
   - 利好 + 不涨（滞涨、收阴、无法收市突破前高）→ "该涨不涨" → 绷紧警惕之弦，视为看跌线索；
   - 利空 + 不跌 → 反向线索（空头警觉）；
   - 反应与消息方向一致 → "正常反应"，本卡结束，后续交给常规技术流程。
   - **判停分支**：无法取得事件后至少 1 个时段的数据 → 判停"观察期未完成"，输出"暂不下结论"。
   - 完成标准：三选一结论 + 依据的价格证据。
4. **试探位登记（"该涨不涨"时）**
   - 登记利好日低点为利空试探位；确认条件 = **收市价跌破**该位 → 信号确认（对接纪律卡的证伪机制与离场动作）。
   - 完成标准：试探位价格 + 确认条件书面化。
5. **采信核对（并行元规则）**
   - 用户引用的说法/数据：查是否有至少两个独立来源证实——单一来源须声明"未获独立证实"；作者自承三星形态仅凭单一来源收录，恰是"采信标准会被自己破例"的警示。
   - 传闻驱动个股 → 回避性结论："远离传言困扰的市场"，不参与。
   - 文化参数元规则：凡遇书中数字（三个窗口、三天确认、8~10 个新高、±10% 等）→ 一律声明为待自测参数，不得直接采信（由差异指数卡/各卡的自测声明承接）。
   - 完成标准：每个被采信的说法附来源数标注。
6. **输出契约**
   - 字段：事件登记 / 反应结论（三选一）/ 试探位 + 确认条件 / 采信声明 / 警惕级别提示。
   - 如实标注：三猿心法（不见邪/不言邪）为姿态性约束，无可检验输出，V2/V3 仅有限通过——不作为步骤交付。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要判断消息真伪、业绩好坏、政策影响——本卡只看价格反应，不做基本面与消息面分析（out of scope）。
- 用户要"消息公布后立即抢进/抢出"的打法——本卡的唯一判据恰是"不要在消息放出后立即开始交易"。
- 用户把"该涨不涨"当确定性卖出指令——它只是"绷紧警惕之弦"的看跌线索，方向指令仍须蜡烛图确认（与摆动指数同为警告级）。

### 作者在书中警告的失败模式

- "耳语战术"：市场内有人散播假消息欺骗交易者——"应该远离传言困扰的市场"。牛顿语："我可以计算出天体的运行，但无法计算人的疯狂。"
- 采信自破（阶段 0 批判）：作者自定的收录标准（至少两个独立来源）由自己为三星形态破例——凡单一来源的形态/说法，采信度最低、识别须最严格核验。
- f45（三猿心法）无完整操作标准：不见邪/不听邪/不言邪是姿态性约束，无法验证执行——本卡只把"不听邪 → 观察反应"这一小段转成可执行步骤。

### 作者的盲点 / 时代局限

- 阶段 0 采信偏差批判（本卡作为路由入口的全局警示叙述）：①收录标准自掌自破；②失败案例从不进入统计呈现，读者看到的是被筛过的成功叙事；③本书兼有 Candlecharts.com 课程体系的营销属性，"蜡烛图独此一家"的强势表述应打折。
- "该涨不涨"判例为 1990 年黄金期货单一叙事，无统计支持"消息反应"规则的普遍有效性（G3）。

### A股制度适配（G2 缺口）

- 涨跌停制度会扭曲消息反应观察：利好高开即一字涨停封板时，"该涨不涨"的核对窗口被迫后移至开板日；停牌复牌的反应观察须单独标注。
- A股利好兑现高开低走是高频模式，但高开低走同样可能是洗盘——本卡只输出"警惕级"，减仓与否须由蜡烛图反转信号与比值核算确认。
- 消息披露时点（盘后公告/午间公告）造成的跳空与 A股集合竞价噪声：反应观察以**收市价**为锚，开盘瞬间反应仅作参考。
