# 蜡烛图数据质量与确认口径门（data-quality-confirmation-gate）

## I — 方法自述

这是一张"进门先验数据"的门卫卡：解读任何 K 线之前先查三件事，任何一件不过就停下或降级，绝不带病分析。

1. **查数据口径**——行情软件的"开盘价"必须是真实开盘价；如果它恒等于前一日收盘价，说明高开/低开信息被整个抹掉，而高开低开本身就是重要信号。此时所有后续判读都建立在残缺数据上，应判停换源。
2. **查确认口径**——形态完成、突破有效、窗口封闭、新价图反转，一律以收市价为准：盘中穿越不算数；周线以周五收盘为准；未收市的蜡烛线是不完整的蜡烛线，不能提前判形态。
3. **查判据版本**——同一形态在不同资料里有宽严两版定义（最典型是乌云盖顶第二日开盘价门槛）。取舍原则是"哪一种说法准确率更高就用哪一种"，落到操作上：选一版、记录在案、全程一致，不得中途混用。

## A1 — 应用示例

原书未提供本单元的独立案例（收市价纪律散见于各形态判例，如窗口支撑"日内一度下跌到窗口下边缘之下，但因为不是收市价……支撑区域保持完好"）。以下为**明确标注的合成演练**（V2 演练沿用，规则全部取自原书）：

- **演练 1（收市价锚）**: 某股盘中最高 11.20、一度上穿 11.00 阻力，收市 10.90 → 突破不成立；次日收市 11.05 → 有效。盘中穿越不算、收市价才算。
- **演练 2（数据口径自查）**: 用户行情软件显示某连续交易个股"开盘价"每日恒等于前收盘 → 高开低开信息丢失 → 判停，要求更换数据源，不做形态判读。
- **演练 3（判据分歧登记）**: 乌云盖顶第二日开市价 11.45：高于前日收市价 11.40 但低于前日最高价 11.60。期货严版（>前日最高价）不成立、股票宽版（>前日收市价）成立 → 本次分析声明采用宽版并记录；严版满足时作"信号更强"档备注。

## A2 — 触发场景 ★

### 用户会在什么情境下需要这张卡？

1. 开始一轮 K 线/形态分析前的例行检查，或刚换了一个行情软件、数据源。
2. 用户描述的现象与图形对不上（"明明高开却没显示"）——怀疑数据口径。
3. 两本书/两个资料对同一形态定义不一致，问"听哪个的"。
4. 盘中提问"已经突破了/破位了"——需要声明收市价确认规则。
5. 周线级别分析——确认"周五收盘"口径。

### 语言信号（中英双写）

- "软件里开盘价怎么和昨天收盘一样"（data feed, real open price）
- "盘中破了算不算 / 盘中突破有效吗"（intraday vs close confirmation）
- "书上两个定义不一样用哪个"（definition conflict, criteria version）
- "周线怎么算 / 周线收盘取哪天"（weekly close）

### 与相邻能力卡的区分

- 与 `single-candle-reading`（C03）的区别：C03 消费数据做单根读数；本卡只做数据与口径门，不产出多空结论。
- 与各形态卡（`window-gap-management-skill`、`two-line-reversal` 等）的区别：形态卡执行各自的确认规则；本卡统一声明"本次分析用哪套确认口径与判据版本"，是它们的公共前置。
- 与 `three-line-break-chart` 的区别：新价图反转同样以收市价为准（口径声明来自本卡），但画法与交易规则在 C23。

## E — 执行步骤

**必需输入**: K 线数据源描述（或行情软件口径说明）+ 本次拟用判据版本（如适用）。用户未说明数据源时询问"你的行情软件开盘价是否为真实开盘价"。
**交付物与完成标准**: 数据可用性结论 + 本次分析的确认口径声明 + 判据版本声明；不通过 → 判停说明。

1. **第 1 查 数据口径自查**
   - 抽查 3-5 根 K 线：开盘价是否恒等于前收盘。恒等 → 高开低开信息丢失 → **判停**，要求更换数据源。
   - A股注意：涨跌停一字板（开=收=高=低）属真实数据但形态信息为零，标注降级而非判停；停牌复牌首日的跳空是信息堆积而非单日多空读数，登记但不判窗口（原书为连续交易市场，未讨论——本条为 A股适配约定）。
   - 完成标准：明确写出"开盘价为真实开盘价"或"判停换源"。

2. **第 2 查 确认口径声明**
   - 声明：形态完成 / 突破有效 / 窗口封闭 / 新价图反转，一律以收市价为准；盘中穿越不算（L2709）；周线按周五收盘。
   - 完成标准：后续每个"成立/有效/封闭"结论均可指出对应收市价数字。

3. **第 3 查 判据分歧处理**
   - 两版定义并存时按"哪一种说法准确率更高就用哪一种"（L327）→ 操作化为**选一版 + 记录 + 全程一致**，不得混用。
   - 登记处：期货严版（乌云盖顶开市 > 前日最高价）与 A股宽版（> 前日收市价）——A股按宽版执行并声明，严版满足时标注"信号更强"档。
   - 完成标准：判据版本声明写入交付物，后续所有形态判定引用同一版本。
   - **判停分支**：用户无法确认数据口径且无替代源 → 停止形态判读，只做价位/趋势描述。

## B — 边界 ★

### 不要在以下情况使用此卡
- 用户只问行情事实（收盘价、涨跌幅），不涉及形态/突破/窗口判定——无口径问题可查。
- 用户明确要求"盘中实时信号"——本卡立场（收市价锚）与之冲突，应先声明分歧而不是假装满足。

### 书中警告的失败模式
- x13（收市价纪律三原句）：日内破窗不算（"市场在日内一度下跌到窗口下边缘之下，但是因为不是收市价……支撑区域保持完好"）；捉腰带线收市反向穿越=失效；未收市蜡烛线不完整。盘中价做决定=用噪声否决结算数据，或用噪声确认未结算的形态。
- 判据混用漂移：两版定义混用会让同类形态忽认忽不认（与 x06 判据弹性失败同源）。

### 作者盲点（阶段 0 批判）
- **无统计回测**（G3）："哪版准确率更高就用哪版"是原则宣示，作者未提供两版准确率的统计比较——该选择本质是先验约定，必须声明而非伪装成书内结论。
- 1990s 美国样本：数据供应商缺陷的描述基于手工绘图/早期软件时代。

### A股制度适配注意
- 期货/股票双口径（G2，注册表指定）：A股个股取股票宽版（>前日收市价即可）并声明。
- 集合竞价与涨跌停：A股开盘价由集合竞价产生且受涨跌停约束，一字板日"真实开盘价"存在但形态不可读；尾盘异动频繁，收市价锚在流动性差的票上可能被反向利用（阶段 0 批判）——小市值股慎用单日收市确认。
- 停牌跳空：复牌首日缺口不按窗口判读（G2 适配约定）。
