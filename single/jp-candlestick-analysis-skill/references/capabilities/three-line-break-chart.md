# 三线反向突破图画法与转向线交易

## R — 原文依据

> "这种图形技术背后的理论是，只有当某个交易时段反向突破此前的三根连续白线（或黑线）时，我们才能画出一根反转线。"
>
> — 史蒂夫·尼森，《日本蜡烛图技术新解》第 6 章"三线反向突破图的画法"（下书第 6 章，规则 10 前说明段，L5633）

---

## I — 方法论骨架 (Interpretation)

三线反向突破图（又称三线反转图、新价三步条形图）是一种只用收盘价、没有时间轴的趋势图。它把"趋势"压缩成黑白竖线的阶梯：创新高画白线、创新低画黑线、落在区间内什么都不画——所以图上留下的只有价格真正推进的记录。

它的独有优点是**无需主观设定反转标准**：白线黑线怎么画是机械的，唯一的"判断"内建在规则里——一旦出现三根连续同色线，趋势即被确认；此后要画反向线，价格必须**超越**（不是触摸）这三根线的极点，画出的那根就是转向线。转向线是趋势警报：黑色转向线结束此前牛市，白色转向线结束此前熊市。

交易体系因此极简：见白线买入、见黑线卖出；转向线是平仓触发器；黑白相间说明无趋势。想更稳可以等转向线之后再等一根同色线（错误率降、利润也降）。它也有一族口诀信号（黑鞋/白套装/脖颈），并可与迭创新低计数、极性转换自由叠加。线数（二线~十线）相当于调整灵敏度——作者的"短/中/长期均线"类比是纯经验映射，须自选验证。

## A1 — 应用示例 (Application Example)

### 示例 1: 墨西哥电信——黑鞋/白套装/脖颈买卖点 + 协会会员的新低计数叠加
- **类型与来源**: 作者转述实盘判例（reported_case），下书下篇第 6 章·图 6-13 墨西哥电信三线反向突破图、图 6-14（日本技术分析师协会会员标注图）
- **问题/输入**: 三线图上的底部与顶部反转结构如何对应买卖点
- **方法论的使用**: 底部：9 月出现小黑线（黑鞋）于 42 美元 → 其后白色转向线（白套装）→ 脖颈伸出 → 按口诀"当脖颈从黑鞋上方的白套装领口伸出来时买入"；顶部 59 美元按镜像口诀卖出。图 6-14：协会会员在三线图上叠加迭创新低计数（市场创下 8 个新低后发生反弹），并把两个阶段峰值（60 美元附近双高点）标为未来阻力
- **结论**: 口诀信号给出买卖点；新价图可与计数器、极性转换自由叠加
- **结果**: 42 美元买入信号、59 美元卖出信号成立；1993 年下半年行情果然受挫于 60 美元阻力区后跌至 45 附近（图注）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户点名要画/解读"三线反向突破图 / 三线反转图 / 新价三步条形图 / 三线转向式"或 "line break / three-line break chart"
2. 用户问"用收盘价序列判断现在是不是牛市/趋势什么时候翻转"，想要一个不依赖主观参数的趋势工具
3. 用户只有收盘价（场外基金净值、无 OHLC 数据）却想做趋势图形分析
4. 用户看到三线图上黑白线相间或转向线，问该怎么操作、何时平仓

### 语言信号 (用户的话里出现这些就应激活)

- "三线反向突破图 / 三线图 / 三线反转图"（three-line break chart, line break）
- "画个线突破图 / 新价图看趋势"（renko/kagi/line-break 泛指时需分流）
- "转向线是什么 / 黑线白线怎么画"（turning line, black/white line）
- "不用参数就能定趋势的方法"（no subjective reversal criterion）

### 与相邻 skill 的区分

- 与 `renko-chart` 的区别: 砖形图有**固定砖值**（变动须达到预定值才加砖、不足不显示、砖等高）；三线图无固定过滤值、线长随价格变动。点名"砖形图/砖值"→ 砖形图卡。
- 与 `kagi-chart-skill` 的区别: 钥匙图有**转向值**（可百分比）且粗细转换（肩/腰、阴阳）；三线图线无粗细、只看三根极点突破。点名"钥匙图/转向值/肩腰"→ 钥匙图卡。
- 与 `new-chart-pipeline` 的区别: 分工卡管"新价图定方向 + 蜡烛图择时"的流水线编排；本卡管三线图自身的画法与信号。画完之后的组合使用走分工卡。
- 与 `new-high-count` 的区别: 迭创新高计数可叠加在三线图上（连续同色线计数），是辅助模块；本卡是画法与交易主体。

## E — 可执行步骤 (Execution)

**必需输入**: 收盘价序列（按交易时段排序）+ 线数声明（默认三线；二线~十线须由用户选定并声明，作者的二线~十线 ≈ 短/中/长期均线的映射为纯经验，G1）。仅提供净值/收益率序列时声明将启用步骤 7 的口径反转。
**交付物与完成标准**: 黑白线序列（每根线的颜色、起点价、终点价、对应的交易时段）+ 转向线事件清单 + 买卖/平仓信号（或收益率口径反转信号）。每根线可由收盘价序列按规则 1–11 复算；画线全部基于**收盘价**，反转确认必须等收盘。

**画法规则 1–11（逐条落进步骤）**：

1. **设基价（规则 1–3：首线）**——把当前收盘价与基价比较：高于基价 → 画白线（底 = 基价，顶 = 今日价）；低于基价 → 画黑线（顶 = 基价，底 = 今日价）；等于基价 → 不画线。完成标准：第一根线的颜色与两个端点价确定（书内示例：基价 135，第 2 时段收 132 → 黑线 135→132）。
2. **第二线（规则 4–6）**——与第一根线的顶、底比较：只有价格**超越**（不是触摸）前线的顶或底才画线：超越前高 → 右移一格画白线（底 = 前高，顶 = 新高）；跌破前低 → 画黑线（顶 = 前低，底 = 新低）；落在区间内 → 不画。完成标准：明确"画/不画"及理由（书内示例：第 3 时段收 128 < 132 → 黑线 132→128；第 4 时段收 133 落于 128~135 → 不画）。
3. **第三线（规则 7–9）**——比较对象升级为**此前所有各线**的最高高点/最低低点：超越所有高点 → 白线（底 = 前一根线的顶）；低于所有低点 → 黑线（顶 = 前一根线的底）；区间内 → 不画。完成标准：同上（书内示例：第 9 时段收 139 > 135 → 白线 132→139）。
4. **三根连续同色线之后（规则 10：三白）**——创新高（哪怕只高一点点）即续画新白线；但画黑线必须等价格跌破**这三根白线的最低点** → 该黑线为**黑色转向线**，高点 = 最高白线的底部，低点 = 今日新低。完成标准：若触发，写出转向线两端点并切换比较对象（书内示例：三白 158→160/160→164/164→167 后，监测区间变为"高于 167 画白线，低于 158 画黑转向线"；第 20 时段收 156 < 158 → 黑色转向线 164→156，高点 = 最高白线的底部 164，低点 = 当日收盘新低 156）。
5. **三根连续黑线之后（规则 11：三黑镜像）**——创新低即续画新黑线；画白线必须等价格升破三根黑线的最高点 → **白色转向线**，起点 = 前一根黑线的顶，高点 = 今日新高。完成标准：同上（书内示例：第 29 时段收 170 < 倒数第三根白线低点 171 → 黑转向线 177→170；第 39 时段收 179 > 177 → 白转向线至 179）。
6. **交易规则（画图完成后）**——①基本信号：见白线买入、见黑线卖出；转向线 = 平仓触发器（黑转向线结束牛市 → 平多；白转向线结束熊市 → 平空）；②黑白相间 = 无明确趋势，不做趋势解读；③确认档位：转向线后再等一根同色线才行动——错误率下降、利润也下降，二选一须声明；④口诀（辅助档）：黑鞋/白套装/脖颈买入；脖颈/黑套装/黑鞋卖出；⑤可叠加迭创新低/新高计数与极性转换（示例 1）。完成标准：每个信号有"动作 + 触发线序号 + 价格"。
7. **参数与口径**
   - 线数：2~10 线均可，灵敏度随线数降低；选线数须声明并长期验证（"短/中/长期均线"类比纯经验，无优化依据，G1）。
   - 收盘价锚：是否构成反转一律等收盘确认（新价图三图共性）。
   - **收益率序列口径反转**：对净值/收益率类序列，收益率越低 = 价格越高 → 反转为**黑线买入**（适用场外基金净值等）。
   - 完成标准：线数声明 + 口径声明写入输出头。
8. **合成演练（可复算示例，非书中案例）**——基价 100，收盘序列 103/106/109/112/110/108/105/102/99：103 → 白 100→103；106 → 白 103→106；109 → 白 106→109；112 → 白 109→112（三白低点 = 106）；110/108 落于 106~112 → 不画；105 < 106 → **黑色转向线 109→105**（高点 = 最高白线底部 109）；102 < 105 → 黑线 105→102；99 < 102 → 黑线 102→99。共 4 白 + 1 黑转向线 + 2 黑。第二组 103/105/107/106/99：三白后 106 落于区间不画线；99 < 三白低点 105 → 黑色转向线（高点 = 105）。完成标准：读者可逐日复算无歧义。

**判停与失败处理**：黑白相间（无三根连续同色线）→ 输出"无趋势，观望"，不做买卖建议；收盘前用户要求"提前画转向线" → 拒绝，只能标注"盘中预判、待收盘确认"（A股 T+1 下建议尾盘临收评估、次日执行——p105 盘中试仓技法依赖 T+0，本土变形待实测，needs_review）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户需要日内择时/逃顶抓底——三线图确认滞后，"新趋势出现很久以后才会出现反转信号"，作者明言它为"只抓行情的主段，而不去找顶或找底"的交易哲学而生。
- 用户要预测价格目标——三线图不提供目标；目标由蜡烛图配套的西方工具供给（分工卡）。
- 用户的数据不是收盘价序列（只有日内分时）——本卡只按收盘价运作。

### 作者在书中警告的失败模式

- x31（拉锯 = 制度性成本）：横盘期黑白相间、信号来回翻转，与砖形图同源的拉锯问题——震荡段照常执行信号会被小亏累积吞掉利润；正确动作是识别横盘状态降频或停用。
- x32（滞后双错位）：拿转向线做精确逃顶/抄底挂单是错位用法（确认时价格已远离极值）；反过来因滞后全盘否定三线图也是错——它负责方向，不负责择时。
- p105 盘中试仓 + 收盘确认技法依赖 T+0（needs_review，不入能力池）——A股不得照搬，按步骤 8 的本土变形声明执行。

### 作者的盲点 / 时代局限

- 线数选择（二线~十线 ≈ 短/中/长期均线）是纯经验映射，无优化与统计依据（G1）；全书无三线图信号的命中率统计（G3）。
- 案例为 1990 年代美股/墨西哥电信，无 A股数据验证。

### A股制度适配（G2 缺口）

- 三线图只用收盘价，T+1 对画图本身无影响；但"见线即动"在 T+1 下实际次日执行，隔夜跳空须提示。
- 涨跌停/一字板：连续一字板会生成连续同色线，计数与"迭创新高/低"读数在极端行情下失真，须在输出中提示。
- 场外基金净值申赎按未知价法成交，与三线图的收盘价假设天然兼容（净值 T+1 公布的滞后须计入）。
