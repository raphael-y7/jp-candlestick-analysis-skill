# 持续形态判定与变体硬纪律

## R — 原文依据

> "我们应当利用前方受阻形态和停顿形态来平仓了结已有的多头头寸，或者为多头头寸采取保护措施，但是不可据之开立空头头寸。"
>
> — 上书《日本蜡烛图技术（第二版）》第六章"白色三兵挺进形态"（图 6.29–6.30）；上升三法判据另见第七章（图 7.21–7.23）

---

## I — 方法自述

持续形态回答的不是"要不要反方向"，而是"当前趋势还能不能续航、我能不能加仓"。三类主体:

1. 上升/下降三法——趋势中的休整: 一根长实体之后跟一小群小实体（理想 3 根、2–5 根可接受），全部局限在首根全部交易范围（含影线）之内；最后以一根同向长实体收创新高（低）收尾——休整结束、趋势继续。
2. 跳空突破——急涨（跌）后小实体群整固，再以同向窗口打开加速；收市回窗口之下即失效。
3. 白三兵——三根依次上升、收市贴近最高价的阳线，是稳健攀升；但它的两个变体（前方受阻、停顿）说的是"多方力气用完了"。注意关键一步: 一方力气用完不等于另一方接管，所以这两个变体只许平多和保护，禁止开空——这是书内明令的硬禁令。

所有持续形态还有一个共同短板: 完成时价格往往已离开起点一段，先核算风险报偿比再谈追。

## A1 — 应用示例

### 示例 1: 斯伦贝谢上升三法被 60 美元阻挡一票否决 + 英特尔止损算法
- **类型与来源**: reported_case，上书第七章·图 7.28 斯伦贝谢、图 7.23 英特尔
- **问题/输入**: 斯伦贝谢 12 月 29 日收出上升三法（2 根小实体的放宽版），能不能买？英特尔例怎么定止损？
- **方法论的使用**: 形态判据本身成立，但恰好在 60 美元阻挡区（12 月 7 日以来）下方——位置一票否决看涨形态；英特尔例给出客观风险算法: 风险从买入点算到上升三法首根白线的最低点。
- **结论**: 阻挡下的上升三法不构成买点；止损参照首根白线低点。
- **结果**: 直到 1 月 11 日收市站上 60 美元阻挡才解除否决（图注）；英特尔案例后续未详（未说明）。

### 示例 2: 微软白三兵——完成时已脱离低位 4 美元的报偿比权衡
- **类型与来源**: reported_case，上书第六章·图 6.32 微软 日蜡烛线图
- **问题/输入**: 标准白三兵（三根白线收市皆近当日最高），能不能追？
- **方法论的使用**: 形态成立，但完成时已脱离低位约 4 美元——短线追买报偿比差，除非长线看好。
- **结论**: "白三兵完成时市场可能已明显脱离低位"——先权衡再追。
- **结果**: 本图后续走势原书未交代（未说明）——作者以此立权衡原则而非给出盈亏。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到"三连阳/红三兵"问能不能追、要不要加仓。
2. 持仓中趋势出现整固（几根小 K 线），问"上升三法成立吗、还能持有吗"。
3. 急涨后的横盘小实体群 + 同向缺口，问"这是不是跳空突破、算不算加速信号"。
4. 涨势中出现"长阳之后一根小阳/带上影线"，有人喊顶部——需要判断是否只是前方受阻/停顿（且必须记住不许开空）。

### 语言信号 (用户的话里出现这些就应激活)

- "白三兵 / 红三兵 / 三连阳"（three white soldiers / three advancing white soldiers）
- "上升三法 / 下降三法"（rising three methods / falling three methods）
- "持续形态 / continuation pattern / 趋势中继"
- "跳空突破 / gap breakout"、"停顿形态 / 前方受阻"

### 与相邻 skill 的区分

- 与 `window-gap-management-skill`（C11）的区别: 跳空突破里的窗口判定、封闭与支撑管理归 C11，本卡只把它当形态要件核对。
- 与 `stop-reward-risk-skill`（C20）的区别: 本卡在"完成价离首根极点过远"时触发比值核算并转出；比值算法与做/不做裁决在 C20。
- 与 `signal-context-filter`（C01）的区别: 形态判定成立后"位置能不能买"的否决（如阻挡下的上升三法）走 C01；本卡输出形态结论与动作档，不重复位置过滤。

## E — 执行步骤

**必需输入**: 3–7 根 OHLC + 趋势背景（上升/下降）+ 成交量序列（可选，用于量核对）。
**交付物与完成标准**: 形态成立与否 + 动作档（持有信心/加仓候选/只平多保护/不成立）+ 回调买区与止损位（白三兵/三法）+ 失效价；每个判据给出"过/不过"记录。

1. **三法判读（逐条核对）**
   - ①首根长实体（方向定上升/下降三法）；②小实体群 2–5 根、理想 3 根（作者自述弹性区间，须声明），全部局限于首根全部交易范围（含影线）——混入一根长实体即不成立（图 7.27 判例）；③末根同向长实体，收市创新高（低）且开市高（低）于前一日收市。
   - 判停: 判据②不满足 → 输出"不成立"，不承担持续承诺。
   - 完成标准: 三条件逐条有结论。

2. **量核对（加分项）**: 首末放量、中间缩量 = 理想量分布。完成标准: 相对量结论（合格/加分/降级）。

3. **报偿比分支**: 完成价距首根极点过远 → 触发风险报偿比核算（止损 = 首根白线最低点），转 C20——比值不划算则放弃或等回抽。
   - 完成标准: 比值已算或已明确转出。

4. **跳空突破分支**: 急涨（跌）+ 小实体群整固 + 同向窗口打开 → 成立；小实体群 + 摆动指数同步回落 = 超买缓解更佳；失效 = 收市回到窗口之下。
   - 完成标准: 成立/失效二值 + 窗口价位。

5. **白三兵分支**: 三根依次上升白线、每根开在前实体内或附近、收市贴近当日最高 → 强势；回调买区 = 第 1/2 根白线实体内部；止损 = 形态起点低点下方。
   - 完成标准: 买区与止损成对输出。

6. **变体硬纪律（判停分支）**: 实体递减或后两根带长上影 = 前方受阻；长阳创新高后跟小实体（骑在肩上或跳空成星）= 停顿——两者只输出"平多/保护"。
   - 判停: 一旦识别为变体，动作档只能取"只平多保护"，禁止输出开空建议。
   - 完成标准: 动作档与硬纪律一致。

7. **并列形态注记**: 并列阳线（白色）出现在下降趋势中 = 看跌持续——窗口方向压倒线体颜色。完成标准: 方向归属有结论。

## B — 边界

### 不要在以下情况使用此 skill

- 据前方受阻/停顿开空——书内明令禁止（R 段原句，x29）。
- 判据"差不多就行"硬凑三法——图 7.25 判例: 长实体混入即排除，判据不满足的"三法"不承担持续承诺（x30）。
- 形态完成后没立即涨就认定失效清仓——信号后未必立即上涨，可能只是"加强支撑区域"，可等回踩形态下沿（x30）。
- 升势晚期（充分上涨后）的三白兵照追——须对超买状态有所戒备（上书第六章），且完成时滞后。

### 作者在书中警告的失败模式

- "不可据之开立空头头寸"——衰竭信号表达的是"一方力气用完"，与"另一方接管"之间隔着验证环节。
- 完成时滞后: 三法/白三兵完成时价格已离开低点，追高须以持仓周期换报偿比（c06/c10 判例）。

### 作者的盲点 / 时代局限

- 全书无统计回测（G3）；"2–5 根小实体"等弹性判据无测试方法论（G1）；样本为 1990 年代美股牛市。

### A股制度适配（G2 缺口）

- A股口语"红三兵"常不要求"收市贴近当日最高"，与本卡白三兵判据不同——须按本卡判据核验后再下结论。
- T+1 下"回调买区"买入当日不可卖，止损按收市价执行（C02 口径）；涨跌停可能截断末根长实体的形态完成。
