# 百分比回撤与价格目标测算

## R — 原文依据

## I — 方法自述

蜡烛图只给方向和时机，不给幅度——幅度要靠本卡的四类几何测算补足。分两侧:

回撤侧: 对一段已完成的 A→B 波段取 38% / 50% / 62% 三档回撤位（50% 最通用）。它们只是"候选位置"，必须有蜡烛信号在场才可买卖——"不在裸回撤位买卖"。

目标侧四式（全部按"把已知高度投影到被突破边之外"的同一思路）:
1. 箱体突破 = 箱体竖直高度加到被突破边之外；
2. 对等运动 = 第一波高度加到调整低点 C；
3. 旗形/尖旗形 = 旗杆长度加到密集区底边（尼森保守算法；与传统"加到顶边"口径并列，选一声明）；
4. 三角形 = 最宽处高度加到被突破边。

所有目标位只有一个身份: 平仓参考位，不是开仓触发器。目标被跌穿不代表"更便宜了"；失效条件（收市回箱体等）触发时目标作废。同一信号配不同目标规则会得出相反的成败结论——目标规则必须固定并声明。

## A1 — 应用示例

### 示例 1: 纳斯达克箱体 2750——目标达成后被跌破，"到位绝不等于可买"
- **类型与来源**: reported_case（TOP15#7），上书第十六章·图 16.2 纳斯达克综合指数
- **问题/输入**: 箱体 3500–4250 被向下突破后目标在哪？到了目标能不能抄底？
- **方法论的使用**: 箱体高度 = 750 点，目标 = 3500 − 750 = 2750；几个月后到达；但市场继续跌破 2750——目标≠支撑；失效条件 = 以收市价回升至 3600（原支撑转阻挡）之上，则 2750 判断作废。
- **结论**: 目标只用于平仓/设定预期，不是买入触发器。
- **结果**: 目标达成后被跌破（原书明示"后来的价格运动低于2750的价格目标"）。

### 示例 2: 康宁与毕玛时——"不在裸回撤位买卖"的两组互验
- **类型与来源**: reported_case，上书第十二章·图 12.3 康宁（15 分钟线）、图 12.4 毕玛时（周线）
- **问题/输入**: 回撤位能不能直接挂单？
- **方法论的使用**: 康宁 8 美元涨幅的 50% 回撤 = 58.50 + 4 = 62.50，11 月 22 日回落至该位出现刺透形态——"回撤 + 蜡烛"双条件齐备才买；毕玛时周线 29 美元 = 50% 回撤（25→33.50 波段）+ 极性转换（A/B/C 峰旧阻挡转支撑）+ 一系列长下影线，三重汇聚。
- **结论**: 裸回撤位只登记不行动，信号验证后才可执行。
- **结果**: 康宁刺透验证支撑；毕玛时三重汇聚后上涨至约 35.5 美元（图注）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "这波看到哪？"——持仓需要目标价/止盈位。
2. "回调到哪可以买？"——等回撤低吸，需要具体档位 + 确认条件。
3. 交易计划要"止损 + 目标"成对出现（喂给风险报偿比）。
4. 看到箱体/旗形/三角形整理，问突破后空间多大。

### 语言信号 (用户的话里出现这些就应激活)

- "目标价 / price target / 看到哪 / 看到XX元"
- "回撤位 / retracement / 38% / 50% / 62% / 斐波那契 / Fibonacci"
- "箱体突破 / range breakout / 对等运动 / measured move"
- "旗形测量 / flag pole / 三角形测算"

### 与相邻 skill 的区分

- 与 `support-resistance-system-skill`（C15）的区别: 前高前低、极性转换位是"观察到的价位"，本卡是"算出来的价位"；C15 供波段端点与结构位，本卡算档位。
- 与 `stop-reward-risk-skill`（C20）的区别: 本卡产出目标的分子与回撤候选入场区；比值核算与做/不做裁决在 C20。
- 与 `signal-confluence`（C14）的区别: 目标位到达时若出现蜡烛信号汇聚，按 C14 处理；目标本身不产生信号。

## E — 执行步骤

**必需输入**: 波段端点 A/B（须为显著极点，选择依据声明）/ 箱体上下沿 / 旗杆起点终点与密集区边界 / 三角形最宽处两沿 + 当前收市价。端点缺失或不显著时询问用户，不静默取值。
**交付物与完成标准**: 三档回撤位 + 目标价位表（注明所用口径）+ 失效条件 + "目标只用于平仓"纪律提示。舍入约定: 中间过程不舍入，末端一次性取整到最小报价单位（股票 0.01 元；ETF/基金按其最小单位），容差 ±1 个最小单位。

1. **波段端点确认**
   - A、B 为显著高/低点（以收市价口径复核，剔除盘中毛刺）。
   - 完成标准: 端点日期 + 价格 + 选择理由。
   - 判停: 端点无法唯一（多重候选）→ 列出各候选对应的档位差异并请用户选定，不静默猜值。

2. **回撤位计算（三档同算）**
   - 上涨波段 A→B: 回撤位 = B − r×(B−A)，r ∈ {38%, 50%, 62%}（书内取整口径: 61.8%→62%、38.2%→38%；50% 最通用）。下跌波段镜像: 回撤位 = B + r×(B−B低点)。
   - 完成标准: 三个数值与手算一致（±1 个最小单位）。

3. **互验纪律（判停分支）**
   - 价格到达回撤位但无蜡烛信号 → 只登记"候选"，不买卖（"不在裸回撤位买卖"）；出现蜡烛信号（刺透/锤子线/吞没等）→ 可执行。
   - 完成标准: 每个回撤位标注"裸/已验证"。

4. **目标测算四式（按形态选用，注明口径）**
   - ①箱体: 目标 = 被突破边 ± 箱体竖直高度（书内例: 50–53→56；3500−750=2750）。
   - ②对等运动: 目标 = 调整低点 C + 第一波高度（书内例: 5.00+24.50=29.50）。
   - ③旗形（尼森保守算法）: 目标 = 密集区底边 + 旗杆长度，看跌从顶边减（书内例: 5.50+36.50=42）——与传统"加到顶边"口径并列（30.5 vs 32），选择后全程一致（G1 声明）。
   - ④三角形: 目标 = 被突破边 ± 最宽处高度（书内例: 137−1.25=135.75）。
   - 完成标准: 每个目标注明所用算式与输入端点。

5. **到位纪律**
   - 目标 ≠ 支撑/阻挡；只用于平仓/兑现，不用于开新仓——除非目标位同时出现同向信号汇聚（转 C14）；"绝不能仅凭行情达到目标便买入"。
   - 完成标准: 输出附纪律提示。

6. **失效监控**
   - 收市价回到被突破边之内（如收市回箱体/回 3600 上）→ 目标作废并撤销相关预案。
   - 完成标准: 失效价与目标成对登记。

## B — 边界

### 不要在以下情况使用此 skill

- 目标被击穿后以"更便宜了"加仓（x19——纳指 2750 教训: 目标不是支撑）。
- 目标位随手取（整数关口/前高/心理位混用）→ 同一形态的胜率评价失去意义（x20——图 4-16 英镑: 极性转换目标 1.85 未达判"信号不可靠"，38% 反弹目标达成判"很成功"，同一信号两种结局）。
- 幅度预期无出处仍填进报偿比分子（x35"不可缘木求鱼"——蜡烛图不预测幅度，分子纯虚构成假纪律）。
- 把回撤位当"到位就买"的铁底（裸位挂单）。

### 作者在书中警告的失败模式

- R 段两条原句: 回撤位须蜡烛信号验证；目标到位绝不等于可买。
- 旗形口径因人而异（下书图 4-16 同一形态两种目标两种结局）——评价信号必须固定目标规则。

### 作者的盲点 / 时代局限

- 斐波那契比率的流行带有文化/神秘色彩，书内无统计检验；波段端点与旗杆起点的选择主观。
- 全部数字例来自 1990 年代美股（G3）。

### A股制度适配（G2 缺口）

- 涨跌停与连续一字板使"箱体高度/最宽处"可能含跳空空白，度量失真时须剔除或声明。
- 除权除息先复权再算，否则波段端点与高度失真（原书未讨论，本土缺口）。
- 最小报价单位按标的调整舍入约定（股票 0.01 元、ETF 0.001 元）。
