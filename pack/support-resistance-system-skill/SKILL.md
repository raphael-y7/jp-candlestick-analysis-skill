# 支撑阻挡体系与假突破反向交易

## R — 原文依据

> "如果某支撑区域最近被向下突破，但市场不能维持，很快回升到支撑区域之上，就可以考虑买进。如果市场坚挺，就不应当跌回最近的低点。最近的低点可以作为止损水平（最好以收市价为标准）。"
>
> — 上书《日本蜡烛图技术（第二版）》第十一章"破低反涨形态"（图 11.11）；趋势线画法另见同章图 11.1

## I — 方法自述

这张卡管两件事。

第一件是画线与破位: 蜡烛图趋势线连影线不连实体——上升支撑线连下影线低点、阻挡线连上影线顶点；至少两点成线、三点更佳；只有收市价穿越才算破位，盘中穿越不算；趋势线接触点上如果同时出现蜡烛信号，效力加持。

第二件是这套体系里少有的"自带止损 + 目标"的完整打法——假突破反向（破低反涨 Spring / 破高反跌 Upthrust）: 支撑被收市跌破又收复（或阻力被收市突破又跌回）时入场，止损 = 最近低点/高点（收市价口径），目标① = 区间顶边/前高（保守），目标② = 更远前高（备用）。量能配合是加分项: 假突破时量轻、收回时量重。

配套的极性转换原则负责记账: 旧支撑被收市跌破 → 登记为新阻挡，旧阻挡被突破 → 登记为新支撑，考验次数越多转换越彻底——这是零成本、高密度的价位来源，喂给目标测算与比值核算。

## A1 — 应用示例

### 示例 1: 思科单时段破高反跌 + 公用事业指数"目标差几个点"的主观性警示
- **类型与来源**: reported_case，上书第十一章·图 11.15 思科、图 11.16 公用事业指数
- **问题/输入**: 假突破出现后怎么定目标？目标一定会到吗？
- **方法论的使用**: 思科 5 月 13 日流星线日内冲破 30 美元阻挡、收市跌回 → 破高反跌在单一时段内完成，目标 = 前低 26.25；公用事业指数 3 月 1 日破低反涨当日收复 308.50 并伴锤子线，目标 = 前高 326。
- **结论**: 破高反跌可单时段完成；目标位有主观性，机械等价触发会错失离场。
- **结果**: 思科目标 5 月 24–25 日达成；公用事业指数两度涨到距 326 仅几个点未触及——作者警示"如果有人一定要等行情准确地到达价格目标，免不了大失所望"。

### 示例 2: 李氏新闻出版——价位×时机×目标的分工微缩全案
- **类型与来源**: reported_case，上书第十一章·图 11.25
- **问题/输入**: 锤子线买点有了，目标在哪？
- **方法论的使用**: 分工链条——极性转换给支撑位（旧阻挡转支撑）→ 锤子线验证支撑并给出约 31.50 美元入场时机 → 下降阻挡线（连 4 月高点）给价格目标。
- **结论**: "蜡烛图不提供目标，西方工具补位"——入场信号与目标工具配对使用。
- **结果**: 作者给出买点与目标的结构；到达与否本段未交代（未说明）。

（补充判例: c16 白银 5.35 支撑回测的三类买方心理建模——极性转换起作用的心理机制: 等企稳的空仓者、被止损出局想"证明自己"的老多头、已入场者的加码盘。）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "这算假突破吗？"——突破支撑/阻力后很快收回，不知该追还是反向。
2. "支撑跌破了/变阻力了吗？"——破位后要不要止损、破位位还能不能用。
3. 想要一套自带止损和目标的完整交易规则（不满足于只有信号没有位）。
4. 画趋势线时不确定连实体还是连影线、破位以什么价确认。

### 语言信号 (用户的话里出现这些就应激活)

- "假突破 / false breakout"（骗线 / 假摔 / 假突破回踩）
- "弹簧线 / spring"、"上插线 / upthrust"、"破低反涨 / 破高反跌"
- "支撑变阻力 / 阻力变支撑 / 极性转换 / polarity shift"
- "趋势线 / trendline"（怎么画 / 破位了吗）

### 与相邻 skill 的区分

- 与 `price-target-retracement-skill`（C16）的区别: C16 是纯计算（回撤位、箱体投影等），本卡是价位结构与假突破判定；C15 的目标位可直接喂给 C20 算比值。
- 与 `stop-reward-risk-skill`（C20）的区别: 本卡产出止损/目标候选价位；比值核算与"做/不做"裁决在 C20。
- 与 `long-term-patterns`（C13）的区别: 颈线识别与破位判定在 C13，破位后的极性转换登记与回抽交易在本卡展开。
- 与 `window-gap-management-skill`（C11）的区别: 窗口判定与封闭归 C11；窗口作为价位结构之一可进入本卡登记表，但不在本卡判定。

## E — 执行步骤

**必需输入**: 价格结构（支撑/阻挡/箱体/趋势线候选点，含各点日期与影线极值）+ 收市价序列。
**交付物与完成标准**: 价位登记表（支撑↔阻挡互转记录）+ 假突破判定 + 入场价/止损价/目标①/目标②/失效条件四件套；所有价位注明口径（收市价确认）。

1. **画线登记**
   - 上升支撑线连下影线低点、上升阻挡线连上影线顶点（下降方向镜像）；≥2 点成线、3 点更佳。
   - 完成标准: 每条线注明连接点（日期 + 影线端点价）。

2. **破位确认**
   - 收市价穿越趋势线/支撑/阻挡才算破位；回抽行为（收复与否）用于判真假。
   - 判停: 仅盘中穿越 → 不动作，登记"假突破候选"继续观察。
   - 完成标准: 破位事件有日期与收市价。

3. **假突破四件套**
   - 触发 = 收市破位后又收市收复（破低反涨）/收市突破后又收市跌回（破高反跌）→ 入场（原书为复位当日可入，可在单一时段内完成；A股见步骤 7 变形）→ 止损 = 最近低点/高点（收市价口径）→ 目标① = 区间顶边/前高（保守）、目标② = 更远前高（备用，起点认定有主观性，须声明）。
   - 完成标准: 四件套价位齐全且成对。

4. **量配合核对**: 假突破时量轻、收回时量重 = 加分（细则归 C04）。完成标准: 量结论输出。

5. **互验**: 假突破与锤子线等蜡烛信号重合 → 互验加权（c09/c13 判例）。完成标准: 共现信号列出。

6. **极性转换登记**
   - 旧支撑被收市破 → 登记为新阻挡；旧阻挡被收市破 → 登记为新支撑；反弹/回踩至该区 = 卖点/买点参考，须与蜡烛信号互验；考验次数越多转换越彻底。
   - 完成标准: 登记表新增条目含来源价位与转换日期。

7. **A股执行变形（G2）**
   - "收市复位确认"使入场自然推迟到确认日；T+1 下当日买入次日方可卖出，隔夜风险计入比值（转 C20）。
   - 完成标准: 执行时点声明（确认日 + 次日可交易）。

## B — 边界

### 不要在以下情况使用此 skill

- 盘中破位就止损/追单——收市价纪律（x13）。
- 把任何"收回支撑"都当 Spring——须有明确的此前支撑/箱体结构，且假突破量轻、收回量重为佳。
- 把极性转换位当"必定反弹/必定受阻"的点——它只是价位参考，须蜡烛信号互验后才行动。

### 作者在书中警告的失败模式

- 目标位有主观性: 公用事业指数 326 目标两度差几个点未触及（c15 判例原句见 A1）——目标附近应分批了结而非挂单等精确价。
- 四重阻力证伪价机制（x23，与 C21 共享）: 35.50 / 36.00×3 / 35.50——收市突破上沿即认错改判，不临时上移阻力位。

### 作者的盲点 / 时代局限

- 备用目标②的起点选择作者自认主观（c14: "在我看来，这轮上冲行情起始于1处；不过，或许有人认为……"）。
- 假突破成效率无统计检验（G3）；样本为 1990 年代美股/外汇。

### A股制度适配（G2 缺口）

- 涨跌停日的"破位又收复"可能无法当日完成（封死跌停），四件套的入场时机顺延。
- T+1 使复位当日买入的隔夜暴露增加，比值核算须计入。
- 尾盘异动可能操纵收市价（阶段 0 批判——收市价锚可能被反向利用），临近收市的复位确认建议复核量能并观察次日开盘。
