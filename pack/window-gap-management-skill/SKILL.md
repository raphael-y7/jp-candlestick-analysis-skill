# 窗口（跳空）判定、支撑管理与趋势终结规则

## R — 原文依据

> "无论两根蜡烛线实体之间的'缺口'有多大，除非在它们的影线之间存在缺口，否则不构成窗口。"（图 7.3）
> "无论已经出现了多少个窗口，当前的趋势都不受影响，直到最后的窗口被关闭为止。"（图 7.8）
>
> — 上书《日本蜡烛图技术（第二版）》第七章"窗口"（图 7.3、图 7.8）

---

## I — 方法自述

窗口（西方叫跳空 gap）在蜡烛图体系里不是一段"价格真空"，而是一个有完整生命周期的支撑/阻挡资产。它的规则链条是:

1. 判定——相邻两根蜡烛线的影线之间互不重叠才算窗口；实体错开、影线搭接的"假跳空"不算，缺口再小（几美分）也算。
2. 登记——整个窗口空间都是支撑（向上窗口，关键支撑在窗口底部）或阻挡（向下窗口，关键阻挡在窗口顶部）；巨量开启的窗口更坚实。
3. 回撤应对——价格回落进窗口是买点（不必精确等到进窗口），止损预先设在"收市跌破窗口底"。
4. 失效——收市价封闭窗口 = 窗口开启前的趋势终结；盘中封闭不算，周线按周五收市。
5. 层级——一个窗口被击穿，就到它下方（上方）找下一个窗口接棒。
6. 裁决权——窗口与其他信号冲突时窗口优先：收市未关窗时，突破阻力线也不做多。
7. 数量纪律——"三"只是文化参考标杆；趋势持续到最后一个窗口被收市价关闭为止，数满三个只做保护性动作、不激进逆势。

这套规则直接对冲本土"缺口理论"的模糊性：不猜回补、不数满即反手，一切以收市价对窗口的处置为准。

## A1 — 应用示例

### 示例 1: 油服指数——锤子线遇上向下窗口，先关窗再信锤子
- **类型与来源**: reported_case（TOP15#5），上书第七章·图 7.7 油服指数 日蜡烛线图
- **问题/输入**: 10 月 8 日急跌中出现锤子线（潜在看涨），但它同时打开一个向下窗口——信号冲突。
- **方法论的使用**: 按"窗口优先"规则，等收市价回到向下窗口顶边之上，才承认锤子线的看涨意义；岛形底完成后，第一支撑取向上窗口位置（约 49.00）而非岛形最低点（45.50）。
- **结论**: 锤子线后两天收市价超越窗口顶边并以向上窗口确认——反转成立。
- **结果**: 行情自岛形底部急升，10 月下旬冲至约 64 美元（图 7.7 图注）。

### 示例 2: 可可"烛光救险"——窗口未关，突破阻力线也不做多
- **类型与来源**: reported_case（TOP15#6），下书《日本蜡烛图技术新解》上篇第 3 章·图 3-50（1992 年 5 月可可）
- **问题/输入**: 3 月中旬收盘价突破一条可追溯到 1991 年 12 月的重要阻力线，线图视角是多头信号。
- **方法论的使用**: 3 月上旬的向下窗口仍开着，窗口顶（1088 美元）未收复 = 趋势仍向下——否决做多。
- **结论**: 多方未能推过窗口顶，突破失败。
- **结果**: 价格受阻回落，避免了一次错误做多——作者称此图"烛光救险"（窗口否决错误交易的判例）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. A股缺口文化高频问句: "这个缺口会不会回补 / 撑得住吗？"
2. 跳空高开/低开之后不知道把缺口当什么位用（能不能挂单买、止损放哪）。
3. 连续三四个缺口之后问"是不是该反手了"。
4. 疑似岛形反转，问第一支撑/第一阻挡取岛形低点还是缺口。
5. 下降趋势中出现放量突破，但上方留有未回补缺口——追不追。

- "岛形反转 / island reversal"

## E — 执行步骤

**必需输入**: 跳空前后数根 OHLC（须通过 C02 数据门: 真实开盘价）+ 已开窗口清单（可由本卡累积维护）+ 标的市场（用于无信息跳空过滤）。
**交付物与完成标准**: 窗口清单表（日期/方向/区间上下沿/状态: 开·封闭·被破）+ 支撑阻挡位 + 事件记录（封闭/层级替代）+ 动作建议（买点区间/止损价/趋势终结判定/保护性动作）。

1. **无信息跳空过滤（A股前置）**
   - 停牌复牌、除权除息、集合竞价、涨跌停一字板造成的跳空先剔除或标注——原书为连续交易市场，未讨论此类跳空。
   - 完成标准: 进入判定的跳空均为正常连续交易时段产生。

2. **窗口判定**
   - 相邻两根蜡烛线影线互不重叠才成立；实体缺口再大、影线重叠即否决。
   - 完成标准: 每个候选跳空给出"是/否窗口"结论。

3. **登记**
   - 整个窗口区间入登记表；向上窗口关键支撑 = 窗口底，向下窗口关键阻挡 = 窗口顶；巨量开启的窗口标注"更坚实"。
   - 完成标准: 区间上下沿有价格、有日期。

4. **回撤应对**
   - 价格回撤接近/进入窗口 → 窗口内为支撑买点（积极者接近上缘即可分批），止损 = 收市跌破窗口底。
   - 完成标准: 买点区间与止损价成对输出。

5. **封闭判定（判停点）**
   - 收市价进入并越过窗口 → 封闭；盘中封闭不算；周线按周五收市。
   - 判停: 封闭 = 窗口开启前的趋势终结——输出趋势终结判定，停止原方向新开仓逻辑。
   - 完成标准: 封闭事件有日期与收市价。

6. **层级替代**
   - 某窗口被收市击穿 → 在其下方（上方）找下一个窗口接棒为支撑（阻挡）；岛形底的第一支撑取窗口而非岛形低点。
   - 完成标准: 替代事件记录新旧窗口与价位。

7. **确认期**
   - 窗口开启后三个交易时段未封闭 → 持续性确认；"不必拘泥于 3"，两/四/五个时段亦可（弹性声明）。
   - 完成标准: 确认状态（未满/已确认）标注在窗口清单。

8. **冲突裁决与三窗口纪律**
   - 收市未关窗时，突破阻力线也不做多（烛光救险规则）。
   - 无论多少窗口，趋势持续到最后一个窗口被收市价关闭；数满三个（及以上）只做对冲/减仓等保护性动作，不激进逆势。
   - 完成标准: 每次形态/窗口冲突给出裁决与依据；窗口计数与当前趋势判定成对输出。

## B — 边界

### 不要在以下情况使用此 skill

- 只有实体缺口（影线搭接）: 不是窗口，别在它上面挂买单或止损（x11——图 7.3 轻质原油 A/B 判例）。
- 把"还没回补"当趋势将反转的理由、把"必回补"当抄底依据（x12）。
- 数满三个窗口就反手开反向仓（x10——黄金图 3-56 判例: 窗口 3 后乌云盖顶只是横盘，窗口 4 被盘中封闭又被守住，激进反手者被碾压）。
- 盘中破窗口下缘就止损/盘中关窗就宣布趋势终结——一切以收市价为准（x13）。

### 作者在书中警告的失败模式

- 作者明确拒绝对"跳空必回补"背书: "在西方，一般认为价格跳空总要被回填。我不知道这一点是不是正确的"（上书第七章）——窗口的正确用法是支撑/阻挡 + 收市封闭为失效条件，不存在"必然回填"的定律。
- "三"是日本文化参考标杆，不是统计阈值（x10 机制说明）。

### 作者的盲点 / 时代局限

- 全部案例来自 1990 年代美股/期货连续交易市场，无统计回测（G3）；"窗口优先"的裁决力是案例归纳。
- 未讨论非连续交易市场的跳空质量差异（阶段 0 批判）。

### A股制度适配（G2 缺口）

- 停牌复牌跳空、除权缺口、涨跌停一字板造成的无信息跳空必须先过滤（步骤 1），否则窗口清单会被无信息缺口污染。
- T+1 下"回撤进窗口即买"当日买入次日才能卖，隔夜风险须计入报偿比（转 C20）。
- 周线窗口按周五收市判定（C02 口径）。
