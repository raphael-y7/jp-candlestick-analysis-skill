## I — 方法自述

十字线（开≈收）是"多空平衡"的读数，它的价值完全来自**对比与环境**，所以这张卡一半是判读、一半是防误用——十字线族是全书公认最高频的误用信号。

流程：定型先行（普通/长腿/墓碑/蜻蜓，高浪十字星按长腿十字星处理）→ 两条位置铁律：北方十字线（上涨中出现）强——尤其长白线之后；南方十字线（下跌中出现）弱——通常不作底部反转信号，除非验证了支撑或伴随巨量；横盘箱体中部出现十字线=没有趋势可反转，直接不动作 → 近似十字线过四问（①邻近行情全是小实体则无意义、若干长蜡烛线之后则同义；②是否正处前高或重要转折点；③是否超买超卖；④有无其他警告信号——"宁可错认也不能漏过"）→ 动作分档：单独一根十字线只把趋势从"上升"下调为"上升或中性"（平部分仓、上调止损），要下调到"下降"必须有第二信号验证 → 登记：长白线之后出现十字线，取两者的最高高点为阻挡、以收市价判突破。

## A1 — 应用示例

### 示例: 长白线之后的十字线——双高点阻挡技巧
- **类型与来源**: reported_case，上书第八章图 8.9 英特尔日线
- **问题/输入**: 涨势中长白实体之后出现十字线（其后是编号 1-7 的连续小实体群）。
- **方法论的使用**: 取长白线与十字线两者的最高高点画阻挡虚线；以收市价判定突破——收市上越=市场"休息好了"、重振雄风的信号；收不上=疲惫持续。
- **结论/结果**: 十字线后英特尔变得"疲惫"，行情随后自约 72 美元区域转跌（图注）——阻挡登记与跟踪规则如式演示。这是十字线族少有的可直接挂位跟踪的规则。

### 合成演练（明确标注；V2 演练沿用）
- 上升趋势创新高后出现 O=C=10.50 十字线 → 四问通过 → 北方十字线 → 趋势"上升"改"上升或中性"、平部分仓；阻挡=max(长白高点, 十字线上影顶)；次日收市 10.30 低于阈值 → 看跌验证成立，才可改判"下降"。
- 对照：同形十字线出现在 10-12 元箱体中部 → 不动作。

## A2 — 触发场景 ★

### 用户会在什么情境下需要这张卡？

1. "涨了这么多，今天收了个十字星，是不是要变盘/见顶"——最高频误用场景，防误用纪律为主。
2. "高位十字星/墓碑线出现了，要不要清仓"。
3. "下跌里的十字星能抄底吗"——南方十字线底部弱化。
4. "长白线后面跟了个十字星，怎么看"——双高点阻挡问句。
5. "开收盘几乎一样的 K 线算十字线吗"——近似判定。

### 语言信号（中英双写）

- "十字星 / 十字线 / 长腿十字 / 墓碑 / 蜻蜓"（doji, long-legged doji, gravestone, dragonfly）
- "变盘 / 见顶信号 / 犹豫"（reversal warning, indecision）
- "开收盘一样"（open equals close）
- "十字星之后怎么操作"（what to do after a doji）

### 与相邻能力卡的区分

- 与 `single-candle-reading` 的区别：C03 判有实体的单根（长实体/纺锤/捉腰带）；开≈收的十字线专属本卡（防实体逻辑误读"平衡"）。
- 与 `signal-context-filter` 的区别：本卡内置了位置判定（北方/南方/箱体）与动作分档，是 C01 流程在十字线族上的专用细化；箱体判停规则两卡一致。
- 与 `star-family` 的区别：十字线作为星线家族中间一根（十字启明/黄昏星、弃婴、崩盘十字星）由 C08 处理；独立单发十字线归本卡。
- 与 `harami-secondary-reversals` 的区别：被长实体包含的十字线=十字孕线，归 C07。

## E — 执行步骤

**必需输入**: 十字线及邻近数根 OHLC + 趋势/箱体环境描述。缺邻近 K 线（无法判断"长实体之后"还是"小实体群之中"）→ 询问补齐。
**交付物与完成标准**: 定型 + 趋势档位调整 + 动作档（保护性动作清单）+ 阻挡/验证价。

1. **定型**
   - 开≈收（差值在几个最小报价单位内）→ 普通/长腿/墓碑/蜻蜓四型；高浪十字星按长腿十字星。
   - 完成标准：型名+开收差值声明（近似认定标准本次声明，G1）。

2. **位置定性与无效排除**
   - 北方十字线（上涨中）=强警讯，尤其长白线之后；南方十字线（下跌中）=弱，通常不作底部反转信号，除非验证支撑或巨量。
   - 箱体中部/邻近全是小实体 → 无趋势可反转，判停"不动作"（图 9.1 十字线 4 判读）。
   - 完成标准：位置结论+判停与否。

3. **近似十字线四问**
   - ①邻近行情全是小实体则无意义、若干长蜡烛线之后则同义；②是否正处前高/重要转折点；③是否超买超卖；④有无其他警告信号。原则"宁可错认也不能漏过"——四问至少一问为"是"才按有效十字线处理。
   - 完成标准：四问逐条作答。

4. **动作分档（防越级改判）**
   - 仅此一信号 → 趋势只下调为"上升或中性"：平部分仓/上调止损，不清仓反手。
   - 次日再留流星线/看跌吞没等验证信号 → 才可下调"下降"。
   - 单凭一根十字线把"上升"改判"下降"=**禁止**（x09）。
   - 完成标准：动作档与趋势档位一一对应，输出保护性动作清单。

5. **验证价与阻挡登记**
   - 长白线后十字线：取两者最高高点为阻挡、以收市价判突破（收上=休整结束重拾升势）；十字星顶点=卖出者的买入止损位（登记）。
   - 完成标准：阻挡价为具体数值，跟踪口径=收市价。

## B — 边界 ★

### 不要在以下情况使用此卡
- "见十字就喊顶"——c26 轶事是本卡的开场警示：某机构交易员课后来信"全办公室的人都在激动地喊着'十字星、十字星'"——零星形态认知只会带来危险。
- 箱体中、小实体群中给十字线定性（x07）。
- 下跌中把南方十字线当买入依据（x08——底部弱化，须等验证）。

### 书中警告的失败模式
- x09（越级改判）："单单凭着一根十字线就把短期趋势从上升调整为下降，我很少这么干"——分级改判是硬规则，一次信号触发全部仓位动作是错的。
- c26/x01（信号兴奋症）：十字线识别门槛极低、带来掌控错觉，群体兴奋放大冲动。
- x08 出处更正（G6）：引用"十字线在下降趋势中一般作用不大"时，出处为上书第九章图 9.1 判读第 8 条（强生案例段），非第七章。

### 作者盲点（阶段 0 批判）
- 无统计回测（G3）：四问法自带主观弹性（书内承认"找不到严格的标准"）；1990s 美国样本；"宁可错认"原则的假信号成本无量化。

### A股制度适配注意
- 涨跌停：一字板日开=收=高=低，机械上"像"十字线但实为流动性锁死，不得按十字线判读——先过数据门（`data-quality-confirmation-gate`）。
- 集合竞价：A股开盘价含集合竞价撮合，开收恰等偶有噪声——近似认定阈值宜宽于最小报价单位并在交付物声明（原书以几美分/几个 1/32 为例，A股无对等刻度，属自定约定）。
- T+1："平部分仓"当日可执行；"次日验证后进一步减仓"意味着验证日收盘决策、其后交易日执行——隔夜跳空风险须写入预案。
