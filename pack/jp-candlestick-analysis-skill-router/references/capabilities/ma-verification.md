# 移动平均线用法与"均线×蜡烛图"验证纪律

## R — 原文依据

> "借助蜡烛图信号验证移动平均线的支撑作用或阻挡作用，然后再采纳其信号来动手建仓或平仓，这是极为重要的考虑，不可轻忽。"
>
> — 上书《日本蜡烛图技术（第二版）》第十三章"移动平均线"（图 13.1）；参数申明另见同章: "它们的时间参数并不是按照最优化的要求选择的。今天最优的移动平均线，明天未必还是最优的。"

---

## I — 方法自述

均线是趋势与持仓成本的代理变量，行情软件人人都有——缺的不是读数，而是纪律。本卡骨架是五用法 + 一条验证闸门:

1. 五用法: 价格与均线的相对位置（趋势指标）、支撑/阻挡、波幅带（包络线）、斜率（在均线上画趋势线监测拐头）、双均线交叉（金叉/死叉只是趋势状态登记，增强条件 = 双均线同向上倾）。
2. 验证闸门（核心）: 不裸按均线交易——价格回落到均线，必须等蜡烛图信号（锤子线、看涨吞没等）在均线处出现、验证了支撑作用，买点才成立。
3. 降级规则: 价格持续运行在均线下方（均线压制）时，一切底部信号一律降级为"企稳观察"——等收市价升破均线再说。
4. 角色转换: 原支撑被收市跌破后就转为阻挡（配合极性转换登记），反弹至该均线区按阻力对待。

本卡只输出条件级结论（"若出现 X 则 Y"），不直接输出买卖指令——读数本身软件可见，纪律才是增值所在。

## A1 — 应用示例

### 示例 1: 欧元兑美元——均线阻挡下，蜡烛底部信号连环失败（趋势过滤第一反例）
- **类型与来源**: reported_case（TOP15#3），上书第十三章·图 13.2 欧元兑美元 日蜡烛线图
- **问题/输入**: 9 天指数加权均线压制的下跌中，2 月初至中旬接连出现两个刺透形态 + 一个看涨吞没，能不能抄底？
- **方法论的使用**: 先查"这次底部信号在均线哪一侧"——价格持续位于均线下方、每次反弹均受阻于该均线 → 全部底部信号降级为"企稳观察"；确认条件 = 收市突破均线阻挡。
- **结论**: 突破未发生就不买——均线阻挡未收市升破前，一切底部信号不作买点。
- **结果**: 三个底部信号全部失败，行情继续下行；作者结论"既然突破的情形没有发生，我们就不应当买进"——回避即正确。

### 示例 2: 合成演练（原书未提供可复算的正例数字例，以下为明确标注的合成演练——注册表 V2 演练）
- **问题/输入**: 股价收市跌破 30 日线后反弹，收市价仍在线下出现看涨吞没。
- **方法论的使用**: 信号在均线下方 → 不买；输出条件级结论"若后续收市重新站上 30 日线，且回踩不破、出现看涨蜡烛信号获均线支撑验证 → 买点成立；否则观望"。
- **结果**: 演算展示"条件级输出"的形态（判定顺序可复现），非真实盈亏。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "站上 30 日线了吗 / 60 日线撑不撑得住？"——软件有读数，但要不要据此行动需要纪律。
2. 均线附近正好出现锤子线/吞没等形态，问"能不能买"。
3. 金叉/死叉出现，问含义与操作。
4. 短参数均线（如 5 日线）反复上下穿越、来回止损，问怎么破。

### 语言信号 (用户的话里出现这些就应激活)

- "均线 / MA / moving average"（30日线 / 60日线 / 半年线 / 年线）
- "金叉 / 死叉 / golden cross / death cross"
- "站上均线 / 跌破均线 / 站稳 20 日线"
- "均线支撑 / 均线压制 / 均线附近买入"

### 与相邻 skill 的区分

- 与 `divergence-index`（C18）的区别: C18 算"价格对均线的偏离百分比"（乖离读数），本卡用"价格与均线的相对位置 + 信号验证关系"，不产出偏离读数。
- 与 `oscillator-confirmation`（C19）的区别: 双均线交叉只是本卡的登记项；摆动指数三要素与"积雨云 vs 下雨"纪律在 C19。
- 与 `signal-context-filter`（C01）的区别: "信号与主要趋势方向一致性"的宏观判断可借均线状态作输入，但四步决策树与动作分派在 C01。

## E — 执行步骤

**必需输入**: 收盘价序列 + 所选均线参数（周期与类型；用户未指定时按步骤 1 默认并声明）+ 均线数值（软件读数或自算）。
**交付物与完成标准**: 均线状态登记（支撑/阻挡/趋势侧/转换）+ 条件级信号（"若出现 X 蜡烛信号则 Y"）+ 降级判定清单；本卡不输出"买/卖"指令，只输出条件与验证要求。

1. **参数与口径声明**
   - 股票参考 30 天 + 5 天、期货 40/65 天、日本口径 5/9/25 日与 13/26 周、75/200 天；声明"参数并非最优化选择，今天最优明天未必"（G1: 按标的自测）。均线类型（简单/指数加权）须写明——类型差异会使位值不同，须固定。
   - 完成标准: 参数、类型、适用条件声明在案。

2. **状态登记（五用法逐一核对）**
   - ①价格与均线相对位置（趋势侧）；②支撑/阻挡历史表现；③波幅带（包络线）；④斜率（在均线上画趋势线监测拐头）；⑤双均线交叉状态（金叉/死叉登记，增强条件 = 双均线同向上倾）。
   - 完成标准: 每项有当前值/状态。

3. **验证闸门（核心判停）**
   - 买入类: 价格回落至均线 + 同价位出现看涨蜡烛信号 → 买点成立；无信号 → 只登记"候选"，不动。
   - 降级类（判停）: 价格持续位于均线下方 → 一切底部信号一律降级为"企稳观察"；未经收市升破均线，不得转买入（图 13.2 欧元反例逻辑）。
   - 完成标准: 每个候选信号给出"验证通过/降级/待验证"三值之一。

4. **角色转换跟踪**
   - 均线原支撑被收市跌破 → 登记为阻挡（图 13.4），反弹至该区按极性转换处理（登记转 C15）。
   - 完成标准: 转换事件入价位登记表。

5. **输出条件级结论**
   - 形如"收市站上 30 日线且次日回踩不破 + 出现看涨信号 → 买点成立；否则观望"。
   - 完成标准: 条件、动作、失效价三者齐备。

## B — 边界

### 不要在以下情况使用此 skill

- 均线阻挡区下抄底——图 13.2 欧元反例: 两个刺透 + 一个看涨吞没连环失败（x14，"这次底部信号在均线哪一侧"是必查项）。
- 短参数穿越做机械买卖——拉锯市来回双杀（x15，图 13.3: 9 月 7–8 日两次穿越失败）；对策是叠加蜡烛验证/拉长参数/识别震荡后停用，而不是调参过拟合。
- 把"今天最优"的参数当永久参数——作者明言"今天最优的移动平均线，明天未必还是最优的"。

### 作者在书中警告的失败模式

- "我们不建议单纯从移动平均线出发，完全根据移动平均线信号来交易"（图 13.1 段末原句）——均线必须与蜡烛图信号互验。
- 参数非最优化申明——书内参数是参考组合，不是调参答案。

### 作者的盲点 / 时代局限

- 作者未给出参数选择方法论与统计检验；"均线上做趋势线"等用法只有示意判例（G1/G3）。
- 样本为 1990 年代美股/外汇。

### A股制度适配（G2 缺口）

- 均线读数软件自带，本卡增值在条件级纪律与降级规则。
- A股 T+1 下"收市升破均线 → 次日买入"之间有隔夜跳空风险，须计入报偿比。
- "年线（250 日）定牛熊"为本土常用经验，原书未提供——采用时按 C02 口径声明并自测，不作为本卡书内判据引用。
