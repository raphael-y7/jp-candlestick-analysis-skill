# 新价图与蜡烛图的分工流水线（宏观定向 + 微观择时）

## R — 原文依据

> "三线反向突破图可以用来判定市场的多空方向，而蜡烛图形可以帮助我们在这个判定的方向中寻找入场时机。"
>
> — 史蒂夫·尼森，《日本蜡烛图技术新解》第 6 章"三线反向突破图与蜡烛图"（下书第 6 章，L5684）

---

## I — 方法论骨架 (Interpretation)

这个方法论回答"手里有三线图/砖形图/钥匙图，还有 K 线图，到底听谁的"。作者的答案是一台两段流水线，各工具只回答自己擅长的问题：

1. **宏观定向**：新价图（三线图连续白线 = 牛市；连续黑线 = 熊市；钥匙图阴阳段、砖形图砖色同理）只依据收盘价、剔除时间噪声，负责回答"现在是什么方向"。它们信号慢，但慢换来了可靠——滤掉的噪声正是逃顶者想抓的那一小段。
2. **微观择时**：方向判定之后，蜡烛图在**这个方向之内**找时机——牛市判定下，多头蜡烛信号才是买点候选，空头蜡烛信号只用于平多保护，**绝不开反方向的仓**；熊市判定下镜像操作。
3. **平仓触发**：基于蜡烛图信号建立的仓位，用新价图的转向线/阴阳转换决定何时平——转向线是趋势的"方向警报"。
4. **警报处理**：黑转向线（或阴转）一出现 → 停止买入逻辑，复核全部持仓。

哲学底线：新价图"抓主段、不逃顶不抓底"，择时交给蜡烛图、方向交给新价图。混用口径（拿慢工具逃顶，或因慢而全盘否定）是这个体系两大典型死法。

## A1 — 应用示例 (Application Example)

### 示例 1: 镊子顶——滞后量化的分工边界
- **类型与来源**: reported_case，下书下篇第 8 章·图 8-17（镊子顶：钥匙图与蜡烛图对照）
- **问题/输入**: 同一标的的顶部，蜡烛图与钥匙图各自何时发出信号？
- **方法论的使用**: 蜡烛图 3 月初已现一系列筑顶形态（微观择时层先动）；钥匙图双顶（镊子顶）4 月初才确认（宏观定向层后动）
- **结论**: 新价图滞后约一个月——这正是分工的原因：拿钥匙图逃顶 = 用错工具；因钥匙图慢而否定它 = 否定错对象。方向归新价图、时点归蜡烛图
- **结果**: 钥匙图 4 月确认 vs 蜡烛图 3 月预警（后续跌幅书中未在此交代，未说明）

### 示例 2: 图 6-4 LILCO——三线图黑转向线 × 蜡烛图空头吞噬的联合判读
- **类型与来源**: reported_case，下书下篇第 6 章·图 6-4a/b（三线反向突破图与蜡烛图，Long Island Lighting 日线）
- **问题/输入**: 9 月初价格升至 29.50 附近，三线图出现黑色转向线；对应蜡烛图同区域出现空头吞噬 + 下降窗口；此前 9 月 3 日的锤子线因出现在下降窗口之后已被否决
- **方法论的使用**: 黑转向线 = 市场转身向下（方向层）；熊市判定下，数日后行情反弹切入下降窗口阻力区内部——只能视为**卖出机会**，不做多头解读
- **结论**: "三线反向突破图确认了熊市的形成，因此几天以后，尽管市场上行，切入下降窗口的阻力区内部，但这只能被看做一个卖出机会"
- **结果**: 行情随后沿黑线下行至 25.5 附近（图注）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户同时拿着 K 线图和三线图/砖形图/钥匙图，问"两边的信号打架了/怎么配合使用"
2. 用户问"现在到底是牛市还是熊市、该买还是该卖"——需要把方向判断和入场时机分开交付
3. 用户抱怨"钥匙图/三线图信号出来太晚了"——需要滞后预期管理与角色澄清
4. 用户想搭一套自己的分析流程（先看什么、后看什么），需要工具分派方案

### 语言信号 (用户的话里出现这些就应激活)

- "三线图和 K 线怎么看 / 怎么配合"（combine line-break with candlesticks）
- "宏观定方向微观找买点 / 分工"（macro direction, micro timing）
- "新价图"（new price charts / new Japanese charting techniques 泛指）
- "信号太晚了还准不准 / 滞后怎么办"（lagging but reliable?）
- "先判断趋势再找入场点"（trend first, then entry）

### 与相邻 skill 的区分

- 与 `three-line-break-chart` / `renko-chart` / `kagi-chart-skill` 的区别: 那三张卡管各图**自身的画法与信号**（机械层）；本卡管**组合编排**（谁定方向、谁定时点、谁触发平仓）。画图请求走对应卡；"怎么一起用"走本卡。
- 与 `signal-context-filter` 的区别: 位置过滤是蜡烛图信号层内部的取舍决策树；本卡在它之上，先决定"允许在哪个方向找信号"。
- 与 `ma-verification` 的区别: 均线也能定趋势方向，但本卡的方向层特指新价图（收盘价、无时间轴）；用户用均线定方向时走均线卡，两套方向来源不混用。

## E — 可执行步骤 (Execution)

**必需输入**: 品种与可用数据形态（有 OHLC → 蜡烛图 + 新价图双轨；仅收盘价/净值 → 仅新价图单轨）+ 已画好的新价图状态（或声明需先走对应画图卡）。
**交付物与完成标准**: ①工具分派方案；②方向判定（含判定来源声明："方向由 X 图的 Y 结构给出"）；③时机清单（每个候选信号注明"买点候选 / 平仓保护"角色）；④平仓触发条件。方向与时机两层各自可追溯、不可互串。

1. **数据盘点与工具分派**
   - 有 OHLC → 双轨：新价图定方向 + 蜡烛图择时。仅净值/收盘价 → 单轨：新价图定方向，蜡烛图层缺席须明示（此时择时能力降级为"转向线/阴阳转换触发"）。
   - 完成标准：分派方案写明"方向工具 = X，择时工具 = Y"。
2. **方向判定（新价图层）**
   - 三线图：连续白线 = 牛市判定，连续黑线 = 熊市判定，黑白相间 = 无趋势；砖形图：砖色趋势同判；钥匙图：阴阳段与肩腰序列同判。
   - **判停分支 1**：无趋势（黑白相间/阴阳等长/翻砖频繁）→ 输出"无趋势，观望"，停止后续步骤，不做买卖建议。
   - 完成标准：方向结论 + 判定结构名（如"三线图第 12~19 时段四根连续白线"）。
3. **方向内择时（蜡烛图层）**
   - 牛市判定下：多头蜡烛信号（锤子线/看涨吞没/启明星等）→ 买点候选（仍须过位置过滤与比值核算）；空头蜡烛信号 → **仅平多/减仓保护，不作开空依据**。
   - 熊市判定下镜像：空头信号 → 卖点候选（A股个人投资者无券可融时输出为"减仓/离场执行点"）；多头信号 → 仅空头平仓/反弹保护。
   - 完成标准：每个信号标注方向角色（顺势候选/逆势保护）。
4. **平仓触发（新价图警报）**
   - 基于蜡烛图信号建立的仓位：转向线（黑转向线/白转向线）或钥匙图阴阳转换 = 平仓时机触发器。
   - **判停分支 2**：黑转向线（多头持仓语境）出现 → 停止买入逻辑，复核全部持仓，输出复核清单。
   - 完成标准：平仓触发条件书面化（"X 图出现 Y 结构即平"）。
5. **滞后预期管理（输出必附）**
   - 新价图确认滞后（镊子顶判例约一个月量级）：方向层晚于择时层是设计而非缺陷；不得用新价图做逃顶抄底，不得因滞后否定其方向价值。
   - 三图共性声明：只依据收盘价、无时间轴、敏感度可调（线数/砖值/转向值自选并声明）。
   - 完成标准：输出尾部附分工边界一句话声明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只要一张图（例如只问钥匙图画法）→ 走对应画图卡；本卡是组合层，单独调用会重复触发画图。
- 用户期待"方向 + 时点"一体化输出（"明天涨还是跌"）——本卡刻意把两层拆开，不做一体化预测。
- 用户只有新价图却坚持要蜡烛图式择时（数据不支持）→ 如实降级，不伪造择时层。

### 作者在书中警告的失败模式

- x32（双错位）：①拿慢工具（钥匙图/三线图/砖形图）逃顶抄底——确认时顶底已过约一个月，追单接半山腰；②因滞后全盘否定新价图、退回凭感觉——忽视分工设计。两种错位都源于"工具答非所问"。
- 图 6-4 判读中的隐含警告：方向判定之前的蜡烛信号会被新价图否决（9 月 3 日锤子线因处于下降窗口之后 + 熊市判定而不作买入信号）——择时层不得越过方向层单独发令。

### 作者的盲点 / 时代局限

- "新价图慢但可靠"是作者的经验判断，无统计检验支撑（G3）；三张新价图之间的选择（三线/砖形/钥匙）也无比较统计，属使用习惯层面。
- 案例全部来自 1990 年代美国市场，无跨市场验证。

### A股制度适配（G2 缺口）

- A股个人投资者做空工具缺位：熊市判定下的"顺势卖点"落地为"减仓/清仓执行点"，不输出开空建议（原书期货语境的做空操作不迁移）。
- T+1：平仓触发（转向线/阴阳转换）当日收盘确认、最早次日执行，隔夜跳空须提示。
- 场外基金（仅净值）：单轨模式的天然适用场景，但净值 T+1 公布使方向判定再滞后一日。
