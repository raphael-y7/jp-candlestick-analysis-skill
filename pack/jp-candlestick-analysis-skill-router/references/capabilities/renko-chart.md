# 砖形图画法与白砖买/黑砖卖

## R — 原文依据

> "价格变动必须到达或超过预定值，否则不能画新砖，这一点是与三线反向突破图不同的地方。"
>
> — 史蒂夫·尼森，《日本蜡烛图技术新解》第 7 章"砖形图的画法"规则 1 注意（下书第 7 章，L6017）

---

## I — 方法论骨架 (Interpretation)

砖形图是三种新价图里规则最单一的一种：预先定一个"砖值"（画一块砖所需的最小价格变动），价格从上一块砖的顶端或底端出发，涨够一个砖值画一块白砖、跌够一个砖值画一块黑砖，砖与砖等高、逐块错位排开。不足一个砖值的变动**不显示**——这就是它的全部过滤机制：噪声被砖值挡在图外，留下来的只有"足够大"的推进。

交易规则也最单一：唯一的反转信号就是砖色翻转——白砖 = 买入信号，黑砖 = 卖出信号。它的魅力在趋势市：一旦单边行情展开，白砖（或黑砖）阶梯会让持有者全程在场，抓住主升/主跌段。代价在横盘市：价格在砖值尺度内往返，白黑交替翻砖，信号连续打脸。

因此使用本图的关键不在画法（机械），而在**砖值选择**与**横盘识别**：砖值要按标的波动率自选；一旦发现近期黑白砖交替、同一价位反复翻砖，就该判横盘、加大砖值或停用信号，而不是怀疑规则。

## A1 — 应用示例 (Application Example)

### 示例 1: 英特尔 2 美元砖 + 长期国债 24/32 砖——抓主段与横盘拉锯的代价
- **类型与来源**: 作者转述实盘判例（reported_case），下书下篇第 7 章·图 7-2 英特尔 2 美元砖形图日线（1992–1993）、图 7-4 长期国债期货周线多头 24/32 砖形图
- **问题/输入**: 白砖买/黑砖卖的单一规则在实盘的表现
- **方法论的使用**: 英特尔：约 22 美元起步的白砖阶梯完整捕获至 72 美元的主升段；中途 28~33 与 50~60 两段横盘各产生一组拉锯信号（B₁-S₁-B₂、B₃-B₄-S₂-S₃-S₄）；国债砖形图：抓住 1993 年大涨主升段，且在 1993 年末至 1994 年初的长期下跌中让多头交易者始终在场外观望
- **结论**: "砖形图技术是一种趋势交易技术……砖形图技术的主要魅力，在于它能让交易者抓住行情的主段"；横盘期的拉锯亏损是其制度性成本
- **结果**: 英特尔主升段（约 22→72）全程持有、横盘段两次拉锯；国债 1993 主升段在场、1993 末–1994 初下跌段场外（图注判读）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户点名"砖形图 / RENKO / 砖头图"，要求画图或解读黑白砖信号
2. 用户抱怨日线图噪声太多，问"有没有把小波动过滤掉的图"——且不排斥固定过滤值
3. 用户问"砖值怎么定 / 多大合适"
4. 用户用砖形图遇到"白砖买了就翻黑砖"的连续假信号，问哪里出了问题

### 语言信号 (用户的话里出现这些就应激活)

- "砖形图 / RENKO / 砖头图"（renko chart）
- "砖值怎么设 / 一块砖代表多少钱"（brick value, brick size）
- "白砖买黑砖卖 / 翻砖了"（white brick buy, black brick sell）
- "过滤噪音的图 / 只看大波动"（filter noise chart — 需与钥匙图/三线图分流）

### 与相邻 skill 的区分

- 与 `three-line-break-chart` 的区别: 三线图无固定过滤值（超越前高/前低即画线，线长随价格）；砖形图有**固定砖值**（到达或超过才画、不足不显示、砖等高）。用户点名"三线"→ 三线图卡。
- 与 `kagi-chart-skill` 的区别: 钥匙图的转向值可设百分比且粗细转换（肩/腰）承载额外信息；砖形图无粗细之分、规则最单一。点名"钥匙图/肩腰/双窗口"→ 钥匙图卡。
- 与 `new-chart-pipeline` 的区别: 分工卡管三图×蜡烛图的编排；本卡只管砖形图自身画法与信号。

## E — 可执行步骤 (Execution)

**必需输入**: 收盘价序列 + 砖值（本币绝对值；未提供时按"砖值须自选、按标的波动率标定"先询问用户，不得静默默认，G1）+ 基价（首时段收盘价即基价）。
**交付物与完成标准**: 砖序列（每块砖的颜色、起止价、对应时段）+ 买卖/卖出信号清单 + 横盘拉锯警示。每块砖可由"与前一块砖的高点/低点之差 ≥ 砖值"复算。

1. **设定砖值与基价**
   - 砖值 = 每画一块砖所需的最小变动数值，同时决定砖高（5 点砖形图每砖高 5 点）。基价 = 首个交易时段收盘价。
   - 完成标准：砖值与基价书面声明（书内教学示例：5 点砖形图、基价 135，表 7-1/图 7-1）。

2. **首砖（规则 1–3）**
   - 规则 1：自基价上涨**达到或超过**砖值 → 画一块或多块白砖（自基价向上，每块代表一个砖值）；规则 2：自基价下跌达到或超过砖值 → 画黑砖；规则 3：变动小于砖值 → 不画。
   - **剩余部分不显示**：涨幅超过砖值但不足两倍只画一块（书内例：5 点砖、基价 100、收 107 → 一块白砖 100→105，107~105 的剩余部分不会显现；收 110 → 两块白砖；跌 13 点 → 两块黑砖、跌 15 点 → 三块）。
   - 完成标准：首砖颜色、起止价确定（书内例：基价 135、第 3 时段收 128，跌 7 点 ≥ 5 → 黑砖 135→130，余 3 不显示）。
3. **后续各砖（规则 4–6）**
   - 规则 4：今日收盘**高于前一块砖（无论黑白）的高点**且幅度达到或超过砖值 → 右移一格画一块或多块白砖，第一块新白砖起点 = 前砖高点。
   - 规则 5：今日收盘**低于前一块砖的底部**且跌幅达到或超过砖值 → 右移一格画一块或多块黑砖，起点 = 前砖底部。
   - **画砖算法（防错，原文规则 4/5/6 与表 7-1 演算例，可机械执行）**：
     1. 参考极点 = 图上**最后画出的那块砖**的近端：要画白砖时参考其**高点**，要画黑砖时参考其**低点**（不是任何更早的砖，也不是收盘价自身）。
     2. 画砖数量 = floor(|收盘价 − 参考极点| ÷ 砖值)，且收盘价必须**越过**参考极点一个完整砖值（恰好到达也算，书内规则4/5用词"到达或超过"）。
     3. 新砖从参考极点起逐块铺设，**每块砖的起止价都必须落在 基价 + n×砖值 的价格网格上**；不足一砖的余额不显示、不累计（书内例：5点砖、前砖高点100，行情到113 → 画两块白砖 100→105→110，3点余额丢弃；后续判定以最后砖 105~110 为基准，不是113）。
     4. 反向砖同样从参考极点起算：白转黑从最后白砖的高点向下铺、黑转白从最后黑砖的低点向上铺——新砖与旧砖**不重叠**。
     5. 书内完整判例：最后砖区间 150~155，行情须达 160 以上才画新白砖、145 或以下才画新黑砖；第14时段收143 → 画一块黑砖 150→145，余额2点不显示。
   - 规则 6：收盘价介于"前砖高点 + 砖值"与"前砖底部 − 砖值"之间 → 不画新砖。
   - 多砖情形：每画一块砖右移一格；超整数倍画多块，余额不显示（书内例：前砖高点 145、收 158 → 白砖 145→150、150→155 共两块，155~158 余额不显示；其后监测区 = 160 以上画白砖 / 145 以下画黑砖）。
   - 完成标准：每根收盘价都有"画/不画 + 理由"的判定记录。
4. **交易规则（白砖买 / 黑砖卖）**
   - 唯一反转信号 = 砖色翻转：白砖出现 → 买入信号；黑砖出现 → 卖出信号。
   - 完成标准：每个信号附砖序号与触发价。
5. **横盘拉锯警示（必做检查）**
   - 近期黑白砖交替出现、同一价位附近反复翻砖 → 判定进入横盘状态：降频、加大砖值或停用信号（先判趋势状态再执行），并如实告知用户"拉锯段的亏损是砖形图的制度性成本"。
   - 完成标准：输出尾部附趋势状态判定（趋势段/横盘段）。
6. **合成演练（可复算示例，非书中案例）**——砖值 5、基价 100：收 107 → 一块白砖 100→105（余 2 不显示）；收 118 → 自前砖高点 105 起涨 13 点 → 两块白砖 105→110→115（余 3 不显示）；收 96 → 自前砖底部 115 起跌 19 点 → 三块黑砖 115→110→105→100（余 4 不显示）→ 卖出信号。横盘（变动均 < 5）→ 无新砖。完成标准：逐块可复算。
7. **判停**：无砖值声明且用户不接受自选 → 判停（本卡无法运行）；序列长度不足（少于约 10 个时段）→ 声明样本不足以判趋势。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户希望图上保留时间信息或影线结构——砖形图无时间轴、无影线，只留收盘价推进；需要多空攻防细节时用蜡烛图。
- 用户把"白砖买黑砖卖"当全天候规则、拒绝横盘降频——本卡必须连带横盘警示一起交付，单独抽走信号规则会造成 x31 式的双杀。
- 用户要目标价与止损位——砖形图不提供；须走目标测算与比值核算。

### 作者在书中警告的失败模式

- x31（原文："行情也会出现横向盘整时期，在这种情况下，行情会出现拉锯（如 B₁-S₁，B₃-S₃，以及 B₄-S₄ 时段）"）：英特尔图上横盘段连续假信号来回止损，盈利来源只是少数几段主升（B₂-S₂、B₅-S₅、B₆-S₆）——横盘期照常满频执行，成本吞掉全部利润。
- 隐含警告（"如果市场趋势明确，砖形图的优势就能体现出来……只有当行情进入横盘整理时，砖形图才会导致频繁的进出"）：规则的简单性以横盘期为代价，不识别市况状态就使用 = 误用。

### 作者的盲点 / 时代局限

- 砖值选择完全由使用者自定，作者未给出按波动率标定砖值的算法，也无任何统计检验（G1/G3）。
- 案例为 1992–1994 年美股与美债期货，趋势偏强的样本期可能高估了"抓主段"的观感（阶段 0：牛市偏差待核查）。

### A股制度适配（G2 缺口）

- 涨跌停/停牌：收盘价跳变会生成大跨度多砖，砖序列在复牌日失真，须在输出中标注异常砖。
- T+1：白砖/黑砖信号出现当日不可执行反向交易，最早次日；隔夜跳空须提示。
- 场外基金净值可套用本画法（只有收盘价），但净值公布滞后一日，信号执行再滞后一日。
