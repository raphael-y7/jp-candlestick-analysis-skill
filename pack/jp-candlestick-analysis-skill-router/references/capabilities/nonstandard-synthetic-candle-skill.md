# 非标准形态三处理法与合成蜡烛线四步法

## R — 原文依据

> "取整个形态中第一个交易时段的开盘价作为合成蜡烛的开盘价；取整个形态中的最高价作为合成蜡烛的最高价；取整个形态中的最低价作为合成蜡烛的最低价；取整个形态最后一个交易时段的收盘价作为合成蜡烛的收盘价。"
>
> — 史蒂夫·尼森，《日本蜡烛图技术新解》第 2 章"蜡烛线组合形态分析"（下书第 2 章，图 2-27b 合成蜡烛线四步，L4279–4285）

---

## I — 方法论骨架 (Interpretation)

教科书上的形态是"标杆"，实际图表里长得完全标准的形态反而是少数。这个方法论回答：一根（或一组）差一点够标准的 K 线组合，到底算不算信号？

作者给了三条路，按顺序取用：

1. **按标准判读，等确认**：先假定它是标准形态读出信号，然后等次日（或下一时段）的更弱收盘来确认——比如切入不到中点的乌云盖顶，就等第二天是否继续维持弱势。
2. **让位置加持**：如果这个非理想形态恰好出现在关键支撑/阻力上，或严重超买超卖区，直接采信——位置可以把"差一点"补齐（例如下影线不够长的锤子线落在 50% 回撤 + 支撑上，按标准锤子线同等对待）。
3. **合成蜡烛判读**：把整组 K 线压缩成一根"合成蜡烛"（首根开盘价 + 全组最高价 + 全组最低价 + 末根收盘价），再用单根法则读它——长上影 = 上方有卖压，长下影 = 低位有承接；合成读数与逐根读数互证。

配套纪律：计算机形态筛选只能处理可量化的标准判据，它排除掉的"近似形态"必须人工复核——机械排除非标准形态是危险的。

## A1 — 应用示例 (Application Example)

### 示例 1: 图 4-14 美国银行"乌云盖顶?"——非标准形态三重加持
- **类型与来源**: 作者转述实盘判例（reported_case），下书第 4 章"计算机与蜡烛图"·图 4-14 美国银行日线
- **问题/输入**: 一组形似乌云盖顶但第二根收市未过前白实体中点的 K 线（软件筛选判为"不成立"），是否放弃？
- **方法论的使用**: 检查加持条件——长上影线（合成判读显示空头属性）+ 压制前期高点（位置）+ 次日照弱（确认）。作者明确："如果这个非标准形态发生在重要阻力位呢？在这种情况下，我会将其视为与传统乌云盖顶形态一样的空头内涵，如果依赖计算机而忽略这个形态的空头信号，显然是危险的"
- **结论**: 非标准乌云盖顶在关键阻力位按标准空头形态同等对待
- **结果**: 作者按空头信号判读（后续行情细节原文未完整展开，未说明）

### 示例 2: 合成蜡烛四步法演算（合成演练，非书中案例）
- **类型与来源**: 原书未提供带完整数字的合成算例，以下为**明确标注的合成演练**（按图 2-27b 四步规则可复算）
- **问题/输入**: 三根蜡烛线：第一根开 10.00、高 10.80、低 9.95、收 10.60；第二根高 11.10、低 10.30、收 10.40；第三根高 10.90、低 10.15、收 10.55
- **方法论的使用**: 四步合成——开盘 = 首根开盘 10.00；最高 = 组内最高 11.10；最低 = 组内最低 9.95；收盘 = 末根收盘 10.55 → 合成蜡烛为小实体（10.00→10.55）位于区间（9.95~11.10）下部 + 长上影
- **结论**: 单根法则读出"上攻受阻（长上影）"而非"强劲上升"，与逐根判读（冲高回落的小实体群）互证
- **结果**: 演算自洽输出；不冒充书中案例，不虚构行情结果

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户指着一组"差一点"的 K 线问"这算不算乌云盖顶/启明星/锤子线"——判据不满足或不完整时的裁决
2. 用户的选股软件/形态筛选器排除了某个近似形态，用户问"要不要信机器"
3. 多根组合（三法/启明星变体）看起来"不太标准"，用户需要一组判读流程而不是直觉
4. 用户明确问"合成蜡烛线是什么/怎么用"

### 语言信号 (用户的话里出现这些就应激活)

- "这算不算/像不像 XX 形态，差一点"（is this a valid dark cloud cover / almost）
- "不算标准的形态/非典型/变体怎么看"（non-standard pattern, variant）
- "软件没识别出来，但我觉得像"（screener missed it）
- "合成蜡烛线/把这几根合成一根"（blended candle, synthetic candle）

### 与相邻 skill 的区分

- 与 `two-line-reversal` / `star-family` / `umbrella-line-family` 的区别: 那三张卡管**标准判据**的逐条核对与强度分级；判据完全满足时走标准卡。判据**不满足/存疑**时才进本卡（三处理法）。两段是流水线上的前后环节。
- 与 `signal-context-filter` 的区别: 位置加持的**流程裁决**（该不该因位置采信）在位置过滤卡；本卡承接其结论执行"加持采信"这一个分支，并提供合成判读工具。
- 与 `data-quality-confirmation-gate` 的区别: 数据口径问题（真假开盘价）不是形态标准性问题——先过数据门，再谈形态标准与否。

## E — 可执行步骤 (Execution)

**必需输入**: 一组构成候选形态的蜡烛线（逐根 OHLC）+ 该组出现的位置描述（支撑/阻力/超买超卖环境，可由位置过滤卡供给）。
**交付物与完成标准**: 合成蜡烛四价格（开盘/最高/最低/收盘）+ 单根法则多空定性 + 三处理法之一的选择与理由 + （若用处理法 ①）次日确认的触发条件。所有四价格必须可由输入逐根复算。

1. **标准判据核对**
   - 先按对应标准卡（吞没/乌云盖顶/刺透、星线族、伞形线族等）逐条核对判据。
   - **判停分支 1**：判据全部满足 → 交给对应标准卡，本卡结束。
   - 判据不满足/存疑 → 进入三处理法选择。
   - 完成标准：判据逐条的满足/不满足清单（注明差在哪一条，如"收市未过中点""下影不足 2 倍"）。

2. **三处理法选择（按顺序尝试）**
   - **法 ①按标准判读等确认**：读出潜在信号 + 明确次日确认条件（例：未过中点的乌云盖顶 → "应该等待观察，看看第二天的行情是否继续维持弱势格局"）。完成标准：确认条件可检验（如"次日收市低于形态低点"）。
   - **判停分支 2**：若法 ① 的位置条件已由位置过滤卡判为关键位置（重要支撑/阻力、50% 回撤位、严重超买超卖区）→ 直接按**法 ②位置加持**采信，输出"按标准形态同等对待 + 依据位置"。原文依据："即使一根锤子线的下影线不是很长……但如果出现的位置正好是行情下跌到前一次涨幅的 50% 附近，那么我会认为，它包含了传统锤子线所蕴涵的所有多头信号价值。"
   - **法 ③合成蜡烛判读**：法 ①② 都不便裁决时执行步骤 3。
   - 完成标准：明确写出选了哪一法 + 为什么。

3. **合成蜡烛四步法**
   - 第 1 步：开盘 = 形态**首根**开盘价。第 2 步：最高 = 组内**最高高点**。第 3 步：最低 = 组内**最低低点**。第 4 步：收盘 = **末根**收盘价。
   - 完成标准：四个价格逐一写出并可由输入复算；合成实体颜色 = 末根收盘 vs 首根开盘。

4. **单根法则判读与互证**
   - 对合成蜡烛按单根法则读数：长上影 = 卖压强/上攻受阻；长下影 = 低位承接/反攻强；小实体 = 呆滞。与逐根判读互证：两者一致 → 结论成立；不一致 → 如实输出两个读数并按保守方向处理（等待确认）。
   - 特判：未过中点的乌云盖顶合成后上影线短 → 信号弱，"应等待确认"。
   - 完成标准：合成定性 + 互证结论（一致/不一致）。

5. **机器筛选复核（凡涉及筛选结果的必做）**
   - 若形态来自软件"形态选股"清单或被其排除：对被排除的近似形态逐个人工复核（本卡步骤 1–4），输出"机器结论 + 人工复核结论"对照。
   - 原文依据："标准形态相对容易量化，可以依赖计算机进行判别，而非标准形态也不容轻易放过，因为它们往往也是重要的市场信号。"
   - 完成标准：每个近似形态有复核结论，无"默认跳过"。

**约定声明（G1）**: 单根法则本身是主观判读——作者致函日本技术分析师协会得到的答复是"我们却喜欢保留灵活性，以免挂一漏万"。本卡不宣称合成判读有统计有效性；弹性边界由使用者的位置过滤标准决定。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 判据已完全满足的标准形态 → 直接走对应标准卡（吞没/星线/伞形线族），本卡的"等确认/加持/合成"只会稀释标准判据。
- 数据本身有问题（开盘价被前收盘冒充、缺最高最低价）→ 先走数据质量门；数据门不过时任何形态判读都判停。
- 用户想要"把任意几根 K 线合成出信号"的自由发挥——合成判读只用于**已构成候选形态**的组合，不是无中生有的信号发生器。

### 作者在书中警告的失败模式

- x18（图 4-14 美国银行"乌云盖顶?"）：计算机机械筛选排除非标准形态是危险的——"最锋利的刀，最应该小心使用"。机械过滤系统性地在关键转折处失明，恰因转折处的形态最不标准。
- x06（判据弹性双向失败）：①判据放宽——把不足倍数的长脚线当锤子线（作者亲自标注图 4.7 的 2 月 22 日"不是锤子线"）；②判据机械——完全硬卡 2 倍/3 倍，漏掉关键位置上略欠标准的真信号；而判据本身两书写法就不一致。

### 作者的盲点 / 时代局限

- 三处理法与合成四步法是作者的经验建议，无任何统计检验；"位置加持"采信的尺度完全依赖主观位置判断（与位置过滤卡共享同一主观性）。
- 作者自承在"追求具体与精确"（西方）与"保留弹性"（东方）之间摇摆——本卡的每次输出都必须声明用的是哪一档弹性。

### A股制度适配（G2 缺口）

- 涨跌停/一字板会造成极端实体与影线缺失，形态判读须先剔除涨跌停造成的失真（一字板的"长实体"不含多空攻防信息）。
- 停牌复牌首日的巨大跳空 K 线不宜按普通长实体/形态判读。
- 原书无 A股案例，本卡全部判读规则为跨市场迁移，适用性自验。
