# 相互验证体系与信号汇聚清点

## R — 原文依据

> "我们对相互验证的定义是'在同一个价位或接近同一个价位上，出现了一群相互验证的技术信号'。相互验证是一个关键概念。其原因在于，在某个支撑区域或阻挡区域，越多的信号汇集在一起，则出现反转的可能性越大。"
>
> — 上书《日本蜡烛图技术（第二版）》第十七章"相互验证"（开篇定义段）；"信息量"三定律另见译者序（丁圣元）

---

## I — 方法自述

这是全书方法论的汇总协议。当某个价位附近出现不止一个信号，不要逐个孤立解读，而要做一次"清点 + 裁决":

1. 先把信号按来源分家系——蜡烛图形态、西方工具、成交量、价位结构（前高前低、趋势线、窗口、均线、回撤位）。
2. 同一家系内的再多个信号只算一票——RSI+KDJ+MACD 是"近亲结婚"，三票其实是一票（信息量三定律: 同一份价格数据的信息量有客观上限，同源工具的结果高度重叠）。
3. 不同家系之间的互证才真正增加信息量——东×西异源验证优于同源堆叠。
4. 清点后给区域定强度: 信号越多越重要；再按强度派动作——"重要"以上才动持仓，"一般"只上调警戒。
5. 两条边界必须随身: 清点回答"这个位置有多关键"，不回答"幅度有多大"；且蜡烛图信号常领先西方工具约一周，别用后者的沉默否决前者。

## A1 — 应用示例

### 示例 1: 纳斯达克 2000 年 3 月顶部——六重信号汇聚的终极研判
- **类型与来源**: reported_case（TOP15#8），上书第十七章·图 17.1/17.1a 纳斯达克综合指数 日线/60 分钟
- **问题/输入**: 纳指 5050–5150 区域是不是主要顶？
- **方法论的使用**: 六重信号同区域汇聚清点——①上升阻挡线（新高区连线，供给区域）；②3 月 10 日日线流星线；③同日 60 分钟图看跌吞没（小周期验证大周期）；④摆动指数顶背离（价新高、指标峰降低）；⑤3 月 10–13 日向下窗口；⑥其后反弹的大风大浪蜡烛线未收市上穿窗口。分属多个家系、同一区域（5050–5150）→ 评级"已见顶"。
- **结论**: 多工具异源汇聚，纳指见顶判断成立。
- **结果**: 纳指于该区域见顶反转、随后大幅调整；作者同时申明"这些工具并不能预测市场向下反转之后即将发生的调整过程的范围"——幅度不可知。

### 示例 2: 捷迪讯（JDS Uniphase）75 美元信号群——区域定级 + 对第一个信号明确放弃
- **类型与来源**: reported_case（次级推荐），上书第十章·图 10.1 JDS 日蜡烛线图
- **问题/输入**: 130 美元急跌至 75 后，第一根巨长看涨吞没能不能买？
- **方法论的使用**: 信号群（看涨吞没、长腿十字线、锤子线、刺透 + 小型向上窗口、平底锅底加窗口）确认 75 美元支撑极稳固；但对第一个信号（4 月 17 日巨长吞没）——完成时已离低点约 25 美元，报偿比否决，明确放弃该次入场、只把 75 定为区域。
- **结论**: 信号群定区域强度 + 逐信号核算报偿比，两步不混。
- **结果**: 75 美元区域支撑稳固，股价其后上行至 135–140 美元（图注）；对第一个信号"放弃"的决策被行情间接验证。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户手里已有一堆信号（"RSI 超卖 + KDJ 超卖 + MACD 底背离 + 前低支撑"），问能不能下单——先做同源/异源裁决。
2. 某价位附近形态、指标、量能扎堆出现，问"这个位置是不是很关键"。
3. 重大顶/底研判（指数或重仓股），要一份可核对的汇聚清单。
4. "共振""多重确认""三重底"这类词出现，需要把口语变成清点协议。

### 语言信号 (用户的话里出现这些就应激活)

- "相互验证 / 信号汇聚 / confluence"（同一位置 / 同一价位）
- "多重确认 / 共振 / triple confirmation / 多信号都指向"
- "RSI+KDJ+MACD 都超卖，能买吗"
- "这个位置是不是很关键 / 支撑很强吗"

### 与相邻 skill 的区分

- 与 `signal-context-filter`（C01）的区别: C01 是入口的位置过滤决策树（单个信号怎么取舍），本卡是价位区域的信号群清点协议——两者构成"先过滤、再清点"的主干。
- 与 `oscillator-confirmation`（C19）的区别: C19 讲摆动指数与蜡烛图的两段式执行（积雨云→下雨）与指标公式；本卡把摆动指数当清点表中的一个家系，不展开公式。
- 与 `volume-confirmation`（C04）的区别: 量能核对细则（理想量分布、积聚/派发）在 C04，本卡只对量能信号计数。
- 与 `support-resistance-system-skill`（C15）的区别: 价位结构家系（趋势线、极性转换位）的画法与登记在 C15，本卡只清点不画线。

## E — 执行步骤

**必需输入**: 候选价位（或区域）+ 该区域可观察信号清单（用户口述/截图转述/自算）。
**交付物与完成标准**: 信号群清点表（分家系列示: 信号名 + 家系 + 方向）+ 区域强度评级（一般/重要/关键——本卡自定义档位，须声明）+ 持仓动作建议 + 边界声明（不预测幅度）。

1. **划区**
   - 以候选价位为中心划定信号搜索区（区域宽度须声明，如 ±2%——本卡约定，原书未给量化标准）。
   - 完成标准: 区域上下沿有数值。

2. **分家系清点**
   - 家系 = ①蜡烛图形态 ②西方工具（趋势线、回撤位、摆动指数、均线）③成交量 ④价位结构（前高前低、窗口、颈线、极性转换位）。
   - 同家系合并计 1 票。
   - 完成标准: 每个信号有家系归属；同族堆叠已被合并。

3. **同源裁决（判停级检查）**
   - 清单中出现"RSI+KDJ+MACD（或同为均线衍生）互证"→ 明确告知不构成多重确认（译者序"近亲结婚"），只计 1 票，并重列可补的异源项。
   - 完成标准: 无同源堆叠残留。

4. **评级**
   - 异源票数单调映射强度——1 票 = 一般（仅上调警戒: 上调止损/缩仓）；2–3 票 = 重要（执行持仓动作: 减仓/了结/分批）；≥4 票且含跨周期验证 = 关键（可做方向性结论）。
   - 声明: 档位划分为候选归纳，原文只给"越多越重要"的单调关系。
   - 完成标准: 评级与票数、家系构成对应可查。

5. **动作输出**
   - "重要"以上才动持仓，"一般"只警戒；买/卖方向还须过 C01 的位置过滤。
   - 完成标准: 动作档与评级一致。

6. **边界记录**
   - 输出末尾固定附: "能预测反转、不能预测幅度"（x35 不可缘木求鱼）；并附时序预期"蜡烛图信号常领先西方工具约一周"。
   - 完成标准: 两条边界声明存在。

## B — 边界

### 不要在以下情况使用此 skill

- 只有同源指标堆叠（三个摆动/均线族指标超卖）→ 不是验证，是幻觉（x34）。
- 信号分布在不同价位（各差 5% 以上）→ 不是"同一区域汇聚"，硬凑无效。
- 用清点表替代位置过滤——箱体中部的"信号群"仍然无意义（先过 C01）。

### 作者在书中警告的失败模式

- 译者序信息量三定律（上书译者序 L139）: 任何手段提取的信息量不可能超过价格数据的信息量极限，同源工具结果重叠——"即使多种手段并用，所得的信息量不一定成正比例增加"。
- x01"一知半解更危险": 把"认得几个信号"当"完成验证"——"全办公室的人都在激动地喊着'十字星、十字星'"（机构交易员来信）。

### 作者的盲点 / 时代局限

- 清点清单的纳入/排除由分析者主观决定，作者未给边界规则；评级分档为本卡候选归纳（G1）。
- "东×西验证增加信息量"的论证框架来自译者丁圣元（信息量概念），非尼森原文；作者立场以蜡烛图为中心（兼有课程营销属性），"蜡烛图将取代线图"的强势表述应打折。
- 样本为 1990 年代美股，无统计回测（G3）。

### A股制度适配（G2 缺口）

- A股软件普遍内置 KDJ/MACD/RSI 且默认参数同源，堆叠幻觉更普遍——同源裁决（步骤 3）在 A股语境优先级更高。
- 本卡评级档位与区域宽度为自定义约定，使用前声明（G1/G3）；"条件选股"类工具输出的形态清单须人工复核（对接 C22 机械筛选警告）。
