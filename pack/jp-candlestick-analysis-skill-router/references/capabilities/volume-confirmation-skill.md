# 交易量验证清单与积聚/派发矩阵（volume-confirmation）

## R — 原文依据

> 上书第十五章："不采用绝对的交易量数值，而是采用相对的交易量……在某只股票上，一个时段内成交5万股可能是一个不同寻常的超大交易量——与此同时，在另一只股票上，一个时段内成交1000万股可能还是较轻的交易量。"
>

## I — 方法自述

量是所有价格信号的可信度加权器，但只做**相对比较**：不看绝对成交量（5 万股在这只票是井喷、1000 万股在那只票是地量），只看相对自身基准的增减与井喷。

方法四层：
1. **理想量分布核对**——给每个形态核对其量能指纹：刺透形态应是黑色轻量白色重量、看跌吞没相反、上升三法首末两根长白量最大、巨量形成的窗口支撑更坚实；不合分布就给信号降级。
2. **特殊判读**——过度上涨后出现巨量十字/纺锤有两种解释（顶部反转疑虑 vs 抛压被吸纳），须后续线确认；巨量锤子线则降低回落风险，可以更积极地在收市买进。
3. **反向限定**——创新高但量缩=后继乏力的警讯，但仅凭量缩不足以由多转空：只减分，不定罪。
4. **积聚/派发矩阵**——同一根放量纺锤线，低价区+价格呆滞=积聚（筹码从惊慌者转给耐心者，看涨）；高价区+放量停滞=派发（出货，看跌）。判读公式=位置 × 相对量 × 实体呆滞度。

## A1 — 应用示例

### 示例 1: 同一根放量纺锤线——低价区积聚 vs 高价区派发
- **类型与来源**: reported_case，下书新解上篇第 2 章图 2-33（1993 年原油）、图 2-34（1991 年 9 月白银）
- **问题/输入**: 原油 1 月 12 日纺锤线+明显放大成交量（当日盘中创新低但空头无力守住）；白银高位巨量+小实体纺锤。
- **方法论的使用**: 先定位价格区（低价区/高价区）→ 查量（相对放量）→ 查线（纺锤=呆滞）→ 次级确认（原油：盘中创新低收不回=卖压被化解；白银：其后系列小实体且最长的实体是黑色=空头立足）。
- **结论/结果**: 原油=积聚信号，"结果都是一波上涨"；白银=典型派发形态，其后下跌（作者判读如实记录）。

### 示例 2: 巨量锤子线——量能加权买点
- **类型与来源**: reported_case，上书第十五章图 15.1 康宁公司 60 分钟线
- **问题/输入**: 5 月 3 日晚间异常巨量+锤子线同现。
- **方法论的使用**: 作者先提醒"应当多加小心"（巨量也可能是恐慌宣泄），随即判读为"交易量验证了价格变化"——长下影+巨量说明低位承接真实，可更积极收市买进；并对比：若锤子线量能不足则保守等待。
- **结果**: 交易量验证成立（作者判读）；该买点后续走势未在本段交代（未说明）。

## A2 — 触发场景 ★

### 用户会在什么情境下需要这张卡？

1. "高位放量滞涨是不是出货"——积聚/派发矩阵的头部问句（A股量价文化下的高频问题）。
2. "低位放量但就是不涨/抗跌，是不是有人吸筹"。
3. "创新高了但成交量缩了，健康吗"。
4. 某个形态（吞没/刺透/三法/锤子线）需要核对量能配合。
5. "今天成交量是平日几倍，怎么看"。

### 语言信号（中英双写）

- "放量 / 缩量 / 天量 / 地量"（volume spike, relative volume）
- "滞涨 / 量价背离"（high volume stagnation, volume divergence）
- "出货 / 吸筹 / 派发 / 积聚"（distribution vs accumulation）
- "量能配合 / 量能验证"（volume confirmation）

### 与相邻能力卡的区分

- 与 `single-candle-reading` 的区别：C03 读价格结构本身；本卡给读数**加权**，不单独产出形态判定。
- 与 `signal-confluence` 的区别：C14 清点信号群时成交量计为一个"家系"；家系内部的量分布核对规则在本卡。
- 与 `divergence-index` 的区别：C18 用价格对均线的偏离量化位置；本卡"低价区/高价区"判断可直接消费 C18 的读数。

## E — 执行步骤

**必需输入**: 量价序列（成交量+对应 K 线）+ 价格区定位（高价区/低价区/中部——用户口述或 `divergence-index` 供给）。缺成交量数据 → 判停本卡（无法加权）。
**交付物与完成标准**: 各信号量能核对结论（合格/加分/降级）+ 积聚或派发判定 + 动作倾向。

1. **建立相对量基准**
   - 只用相对量（对比基准窗口，如近 20 日均量——作者未给算法，基准窗口属**自定义约定**，按标的声明，G1）。井喷=显著超出基准的量。
   - 完成标准：写出基准窗口与当日量/基准比值。

2. **理想量分布核对**
   - 刺透形态=黑轻白重；看跌吞没=白轻黑重；上升三法=首末长白量最大、中间缩量；巨量窗口=支撑更坚实。
   - 完成标准：每个候选信号附"合格 / 加分 / 降级"。

3. **特殊判读四则**
   - 过度延展后巨量十字/纺锤 → 两判读并列（顶部反转疑虑 / 抛压被吸纳），须后续 K 线确认。
   - 巨量锤子线 → 可更积极收市买进（量降低了回落到锤子线低点的可能性）。
   - 创新高量缩 → 后继乏力警讯；仅凭量缩不足以转空（只降级，不做反向开仓依据）。
   - 完成标准：特判结论附条件分支说明。

4. **积聚/派发矩阵**
   - 顺序：先定位价格区 → 查量（相对放量）→ 查线（呆滞小实体/纺锤）→ 次级确认（盘中创新低收不回=积聚加持；其后最长实体为黑=派发加持）。
   - 判定：低价区+放量+价格呆滞=积聚 → 看涨；高价区+放量+停滞=派发 → 看跌。
   - 完成标准：矩阵四步各有一句证据引用。
   - **判停分支**：箱体中部、价格区无法定位 → 不判积聚/派发，仅输出量能核对结论。

## B — 边界 ★

### 不要在以下情况使用此卡
- 无成交量数据，或数据失真（除权/送转日未复权导致量突变）——先修数据。
- 把量能结论当独立买卖信号——量只加权不定罪（量缩≠做空指令）。
- 震荡期"放量"频繁但无方向——积聚/派发矩阵需要明确的价格区定位，箱体中部不判。

### 书中警告的失败模式
- x33（量缩新高的反向限定）：超长白色蜡烛线创新高而量轻——"仅凭缺少交易量这一条并不足以说服我们从看多转向看空，但是它足以构成理由令我们多加小心"。矫枉过正把量缩当反向依据同样是错。
- x17（魔法数字）：相对量基准、理想量分布比例均无统计标定，作者未给算法（G1）。

### 作者盲点（阶段 0 批判）
- 无统计回测（G3）："理想量分布"为案例归纳；1990s 美国做市商市场的成交量结构与 A股竞价市场不同。

### A股制度适配注意
- 原书未讨论：A股存在主力对倒、大宗交易折价过户、集合竞价撮合等使成交量可被人为放大的机制——"放量"读数应结合盘口与后续走势核验，不单独采信（阶段 0"收市价锚可被反向利用"批判的量能类比）。
- 除权除息日须先复权，否则相对量与位置判读双双失真。
- T+1："巨量锤子线当日收市买进"当日可执行，但次日若低开无法当日止损——报偿比须计入隔夜风险。
