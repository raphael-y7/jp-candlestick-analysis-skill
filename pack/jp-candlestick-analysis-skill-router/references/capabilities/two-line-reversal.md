# 双线反转形态判定（含强度分级与两市场口径）（two-line-reversal）

## R — 原文依据

> 上书第四章（吞没形态）："第二根蜡烛线的实体必须覆盖第一根蜡烛线的实体（但是不一定需要吞没前者的上下影线）。"（L691）；（刺透形态）"白色蜡烛线的实体必须向上推进到黑色蜡烛线实体的中点以上。"（L827）
>
> —— 史蒂夫·尼森；引自 transcripts/合并转写稿.md，下同

## I — 方法自述

双线反转是主力反转信号库：**看涨/看跌吞没**（第二根实体完整覆盖第一根实体）、**乌云盖顶**（上涨后阴线切入前阳线实体）、**刺透**（下跌后阳线收复过半）。

三道关卡：
1. **判据本身**——吞没要求此前有明确趋势、实体覆盖（只比实体不含影线；例外：十字线被巨大反色实体吞没）、颜色相反。乌云盖顶/刺透的第二根开盘价门槛有期货严版（须高于前日最高价）与股票宽版（高于前日收市价即可，高于最高价者更强）两版——A股取宽版并声明。
2. **切入深度**——乌云盖顶未切过中点=形态**未完成**，须等下一时段确认或改用合成蜡烛判读；而刺透"必须过中点，没有灵活余地"（作者解释：日本人对底部反转更谨慎，未过中点的看涨序列另分待入/切入/插入三个更弱等级）。
3. **强度与失效**——强度分级看三要素（第一根小实体+第二根长实体最强；连影线都被包裹是下书最严格档；放量加分），但强度排序让位于位置——重要阻力位的乌云盖顶可以强于普通位置的空头吞噬。失效管理：形态高点=阻力、低点=支撑，收市上穿空头形态高点=看跌判断作废、新一轮上涨发端。

## A1 — 应用示例

### 示例 1: 乌云盖顶的机械止损——第 8 天收市上穿即认错
- **类型与来源**: reported_case，下书新解第 4 章图 4-1
- **问题/输入**: 1 月上升趋势停滞形成乌云盖顶压力区，其后 7 个交易日受阻横盘。
- **方法论的使用**: 按形态放空者把止损客观定在乌云盖顶最高点上方；第 8 天出现跳空窗口、收市价高于压力区高点 → 信号翻转。
- **结论/结果**: 空头必须离场。作者批注"一厢情愿的成本总是太高昂"（"倚靠白云的梯子"）；失效价=收市价穿越形态高点，不辩论。图示其后转为上行。

### 示例 2: 乌云盖顶高点转为阻挡——等回测再动手
- **类型与来源**: reported_case，上书第四章图 4.23 英特尔 / 图 4.24 高克联管件
- **问题/输入**: 英特尔 1 月上旬乌云盖顶，形态高点 71 美元；高克联 9 月初 43.25 美元乌云盖顶完成时价格已远离高点。
- **方法论的使用**: 英特尔——71 美元成为阻挡，一周后、两周后三度受阻，1 月 20 日盘中探头但未收市于其上，阻挡有效（日内穿越不算）；高克联——完成时追空报偿比差，等反弹回测 43.25 再卖（10 月上旬四根蜡烛线重复同一高点，后继乏力）。
- **结果**: 英特尔 71 美元阻挡三度有效；高克联给出二次放空点（最终跌幅未说明）。

## A2 — 触发场景 ★

### 用户会在什么情境下需要这张卡？

1. "这算看涨吞没吗 / 吞没形态成立了没"——判据核对请求。
2. "高位出了乌云盖顶/看跌吞没，要不要减仓"。
3. "刺透形态是买点吗，为什么说它没过中点"。
4. "乌云盖顶之后该看什么价位"——极点转化与失效价。
5. 用户拿着软件标注的"吞没"但两根 K 线颜色相同或第一根是十字线——判据例外核对。

### 语言信号（中英双写）

- "吞没 / 吞噬 / 抱线"（engulfing, bull/bear engulfing pattern）
- "乌云盖顶 / 刺透"（dark cloud cover, piercing pattern）
- "覆盖前一根 / 切入中点 / 没过中点"（engulfs prior body, midpoint penetration）
- "信号失效 / 被反包"（invalidation, close above pattern high）

### 与相邻能力卡的区分

- 与 `signal-context-filter` 的区别：本卡判形态成立、强度与失效价；是否行动由 C01 位置闸门决定（图 4-5 强弱倒挂即两卡联动的判例）。
- 与 `harami-secondary-reversals` 的区别：孕线/反击线/平头等弱信号家族在 C07——"第二根实体**被包含**"是孕线（C07）、"**覆盖**"是吞没（本卡），一字之差分家。
- 与 `nonstandard-synthetic-candle` 的区别：未过中点的乌云盖顶属"非标准"，其确认等待/合成判读/位置加持走 C22。
- 与 `stop-reward-risk-skill` 的区别：形态高点=止损锚是本卡输出；比值核算在 C20。

## E — 执行步骤

**必需输入**: 两根 OHLC + 此前趋势方向 + 市场口径声明（宽版/严版，由 `data-quality-confirmation-gate` 登记）。缺口径声明 → 先回 C02 补登记。
**交付物与完成标准**: 形态成立与否 + 强度档 + 阻力/支撑登记 + 失效价（或"未完成，等确认"）。

1. **判据核对（吞没分支）**
   - ①此前须有明确趋势（看跌吞没前=上升，看涨吞没前=下降）；②第二根实体覆盖第一根实体——只比实体不含影线；例外：十字线被巨大反色实体吞没仍可成立；③两实体颜色相反。
   - 完成标准：三判据逐条过/不过并引用具体价格。
   - **判停**：判据不过 → 输出"形态不成立"并停止（禁止 x06 式硬认）。

2. **判据核对（乌云盖顶/刺透分支）**
   - D2 开市口径：期货严版=高于 D1 最高价；股票宽版=高于 D1 收市价即可（高于最高价者更强）→ **A股取宽版并声明**，严版满足时标注"信号更强"档。
   - 收市切入深度：乌云盖顶收市须低于 D1 实体中点，未过=未完成 → 判停输出"未完成，等下一时段确认或转 `nonstandard-synthetic-candle`"；刺透必须过中点、无灵活余地；待入线/切入线/插入线=切入深度递减的看跌持续序列（不构成反转）。
   - 完成标准：写出中点数值与 D2 收市价的比较。

3. **强度分级**
   - 三要素：第一根小实体+第二根长实体=最强；连影线包裹=下书最严格档；第二根放量=加分。
   - 语境排序：日全食（吞没）> 日偏食（乌云盖顶）是默认序，但重要阻力位的乌云盖顶可强于普通位置的空头吞噬——强度档附位置备注（联动 `signal-context-filter`）。
   - 完成标准：强度档+分级依据各一句。

4. **极点转化与失效登记**
   - 形态高点=阻力、低点=支撑（登记进价位表）；失效价：收市上穿空头形态高点 → 看跌判断作废（新一轮上涨发端）；收市下穿看涨形态低点 → 同理作废。
   - 最后吞噬形态注记：位置决定其多空属性（顶部=看跌、底部=看涨），不得凭线色直接定性。
   - 完成标准：交付物含具体失效价数字；后续跟踪以收市价为准（盘中穿越不算）。

## B — 边界 ★

### 不要在以下情况使用此卡
- 无先前趋势的"吞没"——箱体中的反色大实体只是拉锯记录。
- 判据不成立仍按形态行动——x06 的第一类错误；"差不多像"不构成认定。
- 把未过中点的乌云盖顶当已完成形态交易。

### 书中警告的失败模式
- x06（判据弹性）：判据是经验标杆不是充分条件；两书对开盘口径、中点灵活度的表述有差异——先声明版本再判。
- x13（收市价纪律）：未收市的蜡烛线不完整；收市上穿形态高点=失效却抱仓不放（对照图 4-1 止损判例的反面）。
- x02（位置倒挂）：图 4-5 沃尔玛——更标准的空头吞噬因位置差而不可交易；本卡强度档不得脱离位置使用。

### 作者盲点（阶段 0 批判）
- 无统计回测（G3）；1990s 美国样本；"过中点"是硬判据但"足够深"的弹性刻度无定量标准（G1——合成蜡烛可辅助，见 `nonstandard-synthetic-candle`）。

### A股制度适配注意
- 开盘口径（G2，注册表指定）：A股个股取股票宽版（D2 开市 > D1 收市价）并声明。
- T+1：看跌形态触发"减仓"当日可执行；A股无便捷融券时"开空"映射为减仓/清仓+上调止损。
- 涨跌停：D2 一字跌停的"乌云盖顶"可能未及收在中点附近即封板——形态结构被制度截断，标注降级；与窗口同现时联动 `window-gap-management-skill`。
- 停牌复牌：D1 与 D2 之间若隔停牌，趋势连续性存疑——降级为观察（原书未讨论，A股适配约定）。
