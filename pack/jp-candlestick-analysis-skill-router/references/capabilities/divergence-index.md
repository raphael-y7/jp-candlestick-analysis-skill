# 差异指数/偏离指数计算与高低价区标定

## R — 原文依据

> "差异指数也称差异比率，用百分数表示，以收盘价减去移动平均值后的差除以所选定的移动平均值得出。"
> "在你自己的市场中，这个表示极端状态的差异指数峰值或谷底值有可能不是10%，而是别的数据，所以你应该进行反复测试……"
>
> — 下书《日本蜡烛图技术新解》上篇第 5 章"差异指数"（图 5-3～5-7，第二句引文位于图 5-4 前后）

## I — 方法自述

日本资料讲形态前总要先说"行情处于高价区还是低价区"——这个前提在多数书里是拍脑袋，本卡给它一个公式化标尺。

1. 公式: 差异指数 =（收盘价 − 均线）/ 均线，用百分比表示；偏离指数 = 收盘价 / 均线——同一件事的另一种写法（102% 即 +2%，93% 即 −7%）。
2. 三种用法: ①超买超卖——读数到达极端阈值（±10% 只是 13 周线口径的起步值，须按标的自测）时提示投机狂热；②中间状态定趋势——指数上行 = 行情上行；③背离监测——价格创新高而指数峰值低于前峰 = 空头背离。
3. 标定流程: 在自己标的上统计历史读数分布 → 定极端阈值 → 保留有效子集。
4. 关键分工: 极端读数是"积雨云"（狂热提示），不是反转指令——行动必须等蜡烛图信号确认。

A股软件里这个指标叫"乖离率（BIAS）"，公式相同，读数直接可用——本卡补的是标定方法与行动纪律。

## A1 — 应用示例

### 示例 1: Delta 公司股票周线——±10% 超买否决追高（全书唯一纯股票对标案例）
- **类型与来源**: reported_case（TOP15#10），下书第 5 章·图 5-4 Delta 公司股票 周蜡烛图与 13 周差异指数
- **问题/输入**: 差异指数怎么与蜡烛图配合界定高低价区？
- **方法论的使用**: 该股 13 周差异指数 +10%/−10% 为超买/超卖阈值——超卖区（−10% 附近）十字星 + 其后长白线（构成启明星）= 买入确认；⑥处长白线本应看涨，但 +10% 超买读数发出"回避买入"警告。
- **结论**: "差异指数 = 积雨云警告、蜡烛图 = 下雨确认"的分工成立；阈值按标的标定。
- **结果**: ⑥处回避正确（其后确认为最后吞噬顶并走弱）；⑩处锤子线 + 超卖预示走高（图 5-4 判读序列）。

### 示例 2: 合成演练（原书未提供完整可复算的算术例题，以下为明确标注的合成演练——注册表 V2 演练）
- **问题/输入**: 收盘 9.00、13 周均线 10.00；另一日差异指数 +2% 且指数上行；再一日价格创新高而指数峰值低于前峰。
- **方法论的使用与复算**: 差异指数 = (9.00−10.00)/10.00 = −10%，偏离指数 = 9.00/10.00 = 90%（换算自洽: 90% ↔ −10%）→ 超卖读数；+2% 属中间状态且指数上行 → 确认行情上行；峰值降低的价格新高 → 空头背离。
- **结果**: 三种用法各得确定结果，可按 E 段步骤 2–4 复算。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "现在股价偏离均线多少、算不算涨太多/跌太多？"——要一个客观的"高价区/低价区"标尺。
2. 想量化超买超卖，但不想只依赖 RSI/KDJ 的 70/30 常用值。
3. 复盘"高位放量滞涨"时，想核对该位置在历史上到底算不算极端。
4. 监测顶背离/底背离（价格新高而乖离峰值降低）。

### 语言信号 (用户的话里出现这些就应激活)

- "乖离率 / BIAS / 乖离"（A股软件标准叫法——最高频入口词）
- "差异指数 / 偏离指数 / disparity index / deviation index"
- "偏离均线 X% / 偏离 20 日线多少"
- "超买超卖 / overbought / oversold 的量化 / 高价区低价区怎么判定"

### 与相邻 skill 的区分

- 与 `ma-verification`（C17）的区别: C17 用"价格与均线的相对位置 + 蜡烛信号验证"，输出条件级结论；本卡产出"偏离百分比读数"并做阈值标定，两者共享均线参数声明但输出不同。
- 与 `new-high-count`（C10）的区别: C10 数极值根数，本卡算偏离度——"极端"的两路独立读数，可互证。
- 与 `oscillator-confirmation`（C19）的区别: 摆动指数（RSI/随机指数/MACD）公式与阈值归 C19；本卡只管乖离类指标，且同样执行"积雨云"纪律。
- 与 `single-candle-reading`（C03）的区别: 单根读数中"位置定性（低价区/高价区）"需要本卡的量化标尺支撑——C03 消费本卡输出，不生产它。

## E — 执行步骤

**必需输入**: 收盘价序列 + 所选均线参数（如 13 周 / 9 日 / 200 日；须声明均线类型——书内未指明平滑方式，手工简单平均与软件 EMA 读数会不同，固定一种）。
**交付物与完成标准**: 当前差异指数与偏离指数读数 + 相对自定阈值的位置定性（超买/正常/超卖）+ 趋势/背离监测结论 + "等待蜡烛图确认"的行动提示。舍入约定: 百分比保留一位小数；与软件读数差 ≤0.5 个百分点视为口径差，不作为信号差异。

1. **参数与数据声明**
   - 均线周期 + 类型 + 数据区间（周线收市按周五，C02 口径）。
   - 完成标准: 声明项齐全。

2. **计算（顺序固定）**
   - 先算 N 期均线 → 差异指数 = (C−MA)/MA × 100% → 偏离指数 = C/MA × 100% → 交叉校验: 偏离 − 100 应等于差异（例: 102%↔+2%、93%↔−7%，±0.1pct 容差）。
   - 完成标准: 两式换算自洽才算算完。

3. **阈值标定（首次使用必做；本卡补充约定，非原书流程——G1）**
   - 统计该标的过去 ≥3 年（或 ≥250 个时段）读数分布，参考 2σ/95% 分位定极端阈值；±10% 仅为 13 周线起步值（标普期指 13 周口径曾用 ±2%，图 5-5 的 A–F 即 ±2 一线）；保留最近约 20% 数据做样本外核对，阈值在样本内拟合、样本外仍能区分极端段才采用。
   - 完成标准: 阈值 + 统计区间 + 样本外核对结论记录在案。

4. **三用法判定**
   - ①读数越过极端阈值 → 输出"超买/超卖（狂热提示）"；②中间状态 → 按指数斜率输出趋势确认（上行 = 行情上行）；③背离 → 价格新高（新低）而指数峰值更低（更高）→ 输出"空头（多头）背离"。
   - 完成标准: 三项各有结论或"不适用"。

5. **行动纪律（判停）**
   - 极端读数本身不触发任何买卖——只提示关注；行动条件 = 同区域出现蜡烛图信号（十字星/吞没/锤子线等）才执行（"积雨云"分工，与 C19 一致）。
   - 完成标准: 输出末尾附"等待确认清单"（缺哪个蜡烛信号）。

## B — 边界

### 不要在以下情况使用此 skill

- 照搬 ±10% 到不同波动率的标的——低波股永远到不了（信号饥饿）、高波股天天越过（信号泛滥）（x17）。
- 把高企读数当"必然反转"提前做空/清仓——原书定位是"投机狂热提示"，不是反转指令。
- 只用单日读数不看分布——未经标定的阈值无意义。
- 用乖离背离替代蜡烛图确认——背离也只是警告级（x16 同理）。

### 作者在书中警告的失败模式

- "峰值或谷底有可能不是10%……你应该反复测试"（R 段原句，x17 的原文依据）。
- 日经偏离指数参考表（1980 年代、2σ 口径；200 日偏离 >110% ≈ 过热/接近牛尾提示）仅为"自测标定方法"示范，不得直接引用阈值（p99 时效声明）。

### 作者的盲点 / 时代局限

- 作者鼓励自测却没给样本设计与显著性检验方法论——无样本外纪律的自测 = 数据挖掘/过拟合风险（f37 警示区，阶段 0 最强反对意见④）；步骤 3 的最小测试设计是本卡补充约定，非原书内容。
- 日经参考表数据时效已过 40 年（G3/p99）。

### A股制度适配（G2 缺口）

- A股软件"乖离率 BIAS"即同公式，读数直接可用；周线 13 周口径对 A股周线同样适用。
- 涨跌停与停牌会造成均线与读数跳变（复牌首日乖离瞬间拉大），标定与判读时剔除或标注（原书未讨论，本土缺口）。
